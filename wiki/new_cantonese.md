# Java 中的 "new" 關鍵字：創建物件的基石

## 簡介
在 Java 編程語言中，"new" 是一個關鍵字，用於創建物件的實例。它是物件導向編程的重要組成部分，允許開發者動態分配記憶體並初始化類的實例。

## 文檔
### 目的
"new" 關鍵字的主要目的是創建一個類的實例並在堆記憶體中分配所需的空間。這樣，開發者可以使用該實例來調用類中的方法和訪問屬性。

### 使用方法
當使用 "new" 關鍵字時，必須指定要創建的類名，並可以選擇性地傳遞參數以調用類的構造函數。基本語法如下：

```java
ClassName objectName = new ClassName(parameters);
```

### 詳細說明
- **類的實例化**：使用 "new" 創建的物件是根據類的定義來初始化的，這包括類的屬性和方法。
- **構造函數**：可以使用默認構造函數或自定義構造函數來初始化物件。如果有自定義構造函數，必須提供相應的參數。
- **記憶體管理**：使用 "new" 會在堆內存中分配空間，並且這些物件的生命週期由垃圾收集器負責。

## 示例
以下是使用 "new" 關鍵字創建物件的基本範例：

```java
// 定義一個類
class Dog {
    String name;

    // 構造函數
    Dog(String name) {
        this.name = name;
    }

    void bark() {
        System.out.println(name + " says woof!");
    }
}

// 使用 "new" 創建物件
public class Main {
    public static void main(String[] args) {
        Dog myDog = new Dog("Buddy");
        myDog.bark(); // 輸出: Buddy says woof!
    }
}
```

## 解釋
- **常見陷阱**：在使用 "new" 創建物件時，若未提供正確的參數，會導致編譯錯誤。此外，忘記調用構造函數中的 super() 可能會影響物件的初始化。
- **記憶體洩漏**：雖然 Java 有垃圾收集，但不當使用會導致記憶體洩漏，特別是在長時間運行的應用中。
- **不可變物件**：在創建不可變物件時，需特別注意構造函數的設計。

## 總結
"new" 關鍵字在 Java 中是創建物件的基石，正確使用它可以有效管理物件的生命週期和資源。
