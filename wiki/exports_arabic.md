# تصدير الحزم في جافا: دليل شامل لفهم واستخدام الأمر `exports`

## الملخص
تعتبر خاصية `exports` في جافا جزءًا حيويًا من نظام الحزم (modules) الذي تم تقديمه في Java 9، حيث تسمح للمطورين بتحديد الحزم التي يمكن استخدامها خارج الوحدة (module) الخاصة بهم، مما يعزز من تنظيم الكود وسهولة الصيانة.

## الوثائق
### الغرض
تعمل خاصية `exports` على تحديد الحزم التي يمكن أن تكون متاحة للاستخدام من قبل وحدات أخرى. هذا يساهم في تحسين أمان التطبيق من خلال تقليل عدد الحزم التي يمكن الوصول إليها، وبالتالي تقليل فرص حدوث تعارضات أو أخطاء.

### الاستخدام
يتم استخدام أمر `exports` داخل ملف تعريف الوحدة (module-info.java) لتحديد الحزم التي تريد تصديرها. الشكل العام للأمر هو:

```java
module اسم_الوحدة {
    exports اسم_الحزمة;
}
```

يمكنك تصدير عدة حزم عن طريق تكرار الأمر `exports`:

```java
module اسم_الوحدة {
    exports اسم_الحزمة1;
    exports اسم_الحزمة2;
}
```

### التفاصيل
- يمكن تصدير الحزم إلى وحدات معينة باستخدام الأمر `to` كما يلي:

```java
module اسم_الوحدة {
    exports اسم_الحزمة to اسم_الوحدة_المستهدفة;
}
```

- إذا لم تقم بتحديد أي وحدات، فإنه سيتم تصدير الحزمة لكل الوحدات.

## الأمثلة
### مثال 1: تصدير حزمة واحدة
```java
module my.module {
    exports com.example.myapp;
}
```

### مثال 2: تصدير عدة حزم
```java
module my.module {
    exports com.example.myapp;
    exports com.example.utils;
}
```

### مثال 3: تصدير حزمة لوحدة معينة
```java
module my.module {
    exports com.example.myapp to another.module;
}
```

## الشرح
### الأخطاء الشائعة
- **نسيان استخدام `exports`**: من الشائع أن يقوم المطورون بنسيان تصدير الحزم الضرورية، مما يؤدي إلى عدم القدرة على استخدام الكود من وحدات أخرى.
- **تصدير غير صحيح**: تأكد من أن أسماء الحزم صحيحة وأن الوحدات المستهدفة متاحة، حيث أن أخطاء التهجئة يمكن أن تؤدي إلى أخطاء في الترجمة.

### ملاحظات إضافية
- تأكد من فهم بنية المشروع الخاص بك بشكل جيد، حيث أن تنظيم الحزم والوحدات يمكن أن يؤثر على طريقة تصديرها.
- استخدم `exports` بحذر لضمان أن الكود الخاص بك يبقى آمنًا وقابلًا للصيانة.

## ملخص جملة واحدة
تساعد خاصية `exports` في جافا على تنظيم الكود من خلال تحديد الحزم التي يمكن استخدامها بواسطة وحدات أخرى، مما يعزز من أمان التطبيق وسهولة الصيانة.
