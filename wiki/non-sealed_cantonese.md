# Java 非密封 (non-sealed) 類別：了解 Java 17 的新特性

## 簡介
在 Java 17 中，引入了「非密封」(non-sealed) 類別的概念，用於更靈活地控制繼承結構。這個特性允許開發者更自由地擴展密封類別的子類別，從而提高代碼的可擴展性和可維護性。

## 文檔
### 目的
非密封類別的主要作用是允許開發者在密封類別的基礎上創建更多的子類別。這使得在某些情況下，開發者可以選擇不限制其子類的繼承，從而提高靈活性。

### 用法
在定義一個非密封類別時，需要使用 `non-sealed` 關鍵字，這個關鍵字可以放在類別定義的開頭。這樣做會告訴編譯器，這個類別可以被其他類別繼承，而不受封閉的限制。

### 詳細說明
- **密封類別**：密封類別是指只能有特定的子類別可以繼承的類。這在 Java 17 中是通過 `sealed` 關鍵字來實現的。
- **非密封類別**：使用 `non-sealed` 關鍵字的類別，無論是任何其他的類別都可以繼承它，這使得繼承的結構變得更加靈活。
- **使用場景**：當開發者希望保留某種程度的控制權，但又不希望完全限制繼承時，使用非密封類別是一個理想的選擇。

## 示例
```java
// 定義一個密封類別
sealed class Animal permits Dog, Cat {}

// 定義一個非密封的子類別
non-sealed class Dog extends Animal {}

// 定義一個其他子類別
class Cat extends Animal {}
```
在上述示例中，`Animal` 是一個密封類別，只允許 `Dog` 和 `Cat` 繼承。`Dog` 類是非密封的，這意味著可以有其他類別繼承 `Dog` 類，而 `Cat` 則是密封的，無法再被繼承。

## 解釋
- **常見陷阱**：確保非密封類別的設計是合理的，因為過度使用非密封類別可能會導致代碼的複雜性增加。
- **注意事項**：使用 `non-sealed` 時，應該考慮到未來的擴展性，避免不必要的繼承層次。

## 一句話總結
Java 中的非密封類別允許開發者靈活地擴展密封類別的子類別，從而提高代碼的可維護性和可擴展性。
