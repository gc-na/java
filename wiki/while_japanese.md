# Javaの「while」ループ：使い方と実例

## 概要
Javaの「while」ループは、条件が真である限り、特定のコードブロックを繰り返し実行するための制御フロー文です。このループは、条件が変化するまで実行を続けるため、動的な反復処理に適しています。

## ドキュメンテーション
### 目的
「while」ループは、指定した条件が成立している間、繰り返し処理を実行します。これは、データの入力処理や、特定の条件が満たされるまでの繰り返し処理に有用です。

### 使用法
「while」ループの基本構文は次の通りです：

```java
while (条件) {
    // 実行するコード
}
```

- **条件**: boolean式であり、真の場合にループが実行されます。
- **実行するコード**: 条件が真である限り、繰り返し実行されるコードブロックです。

### 詳細
- ループの前に条件が評価されるため、条件が初めから偽の場合、ループ本体は一度も実行されません。
- ループの中で条件を変更しないと、無限ループに陥る可能性があります。
- 複雑な条件評価や多くの処理が必要な場合は、ループの外部で条件を設定することが重要です。

## 例
### 基本的な使用例
```java
int count = 0;
while (count < 5) {
    System.out.println("カウント: " + count);
    count++;
}
```
この例では、`count`が5未満の間、カウントを出力し、`count`が1ずつ増加します。

### ユーザー入力の例
```java
import java.util.Scanner;

public class UserInput {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String input;
        
        System.out.println("終了するには 'exit' と入力してください。");
        
        while (true) {
            input = scanner.nextLine();
            if (input.equals("exit")) {
                break;
            }
            System.out.println("あなたが入力したのは: " + input);
        }
        
        scanner.close();
    }
}
```
このコードは、ユーザーが「exit」と入力するまで、入力を受け取り続けます。

## 説明
### 一般的な落とし穴
- **無限ループ**: 条件が常に真である場合、プログラムが終了しなくなることがあります。条件の更新を忘れずに行うことが重要です。
- **条件の複雑さ**: 条件が複雑すぎると、意図しない動作を引き起こすことがあります。十分にテストし、必要に応じて簡素化することが推奨されます。

### 注意点
- `while`ループは、繰り返し回数が事前にわからない場合に特に有効です。
- 代わりに`for`ループを使用することも可能ですが、`for`ループは回数が決まっている場合に適しています。

## 一文要約
Javaの「while」ループは、条件が真である限り繰り返し処理を実行するための強力な制御フロー文です。
