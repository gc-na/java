# استيراد في جافا: فهم الأهمية والاستخدامات

## ملخص
تُستخدم كلمة "import" في لغة البرمجة جافا لاستيراد الحزم (Packages) أو الفئات (Classes) من مكتبات خارجية أو من مكتبة جافا القياسية، مما يسهل الوصول إلى الوظائف والخصائص التي توفرها.

## الوثائق
### الغرض
تُعتبر عبارة "import" جزءًا أساسيًا من جافا، حيث تسمح للمطورين بالاستفادة من الكود الموجود في حزم أخرى بدلاً من كتابة كل شيء من الصفر. تسهل هذه العبارة تنظيم الكود وإعادة استخدامه، مما يحسن من كفاءة التطوير.

### الاستخدام
تستخدم عبارة "import" في بداية ملف جافا قبل تعريف الفئة الرئيسية. يمكن استيراد حزمة كاملة أو فئة معينة منها. الصيغة العامة للاستخدام هي:

```java
import packageName.ClassName; // لاستيراد فئة معينة
import packageName.*;          // لاستيراد جميع الفئات من حزمة
```

### التفاصيل
- **استيراد فئة معينة**: إذا كنت بحاجة إلى استخدام فئة واحدة، يمكنك استيرادها بشكل مباشر.
- **استيراد كل الفئات**: إذا كنت بحاجة إلى استخدام عدة فئات من نفس الحزمة، يمكنك استخدام علامة النجمة (*) لاستيراد جميع الفئات.

### أمثلة
#### مثال 1: استيراد فئة واحدة
```java
import java.util.ArrayList;

public class Example {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();
        list.add("Hello");
        System.out.println(list);
    }
}
```

#### مثال 2: استيراد جميع الفئات من حزمة
```java
import java.util.*;

public class Example {
    public static void main(String[] args) {
        HashMap<Integer, String> map = new HashMap<>();
        map.put(1, "One");
        System.out.println(map);
    }
}
```

## الشرح
### الأخطاء الشائعة
- **عدم استيراد الحزم المطلوبة**: إذا نسيت استخدام عبارة "import" لفئة تحتاج إليها، ستحصل على خطأ في التجميع (Compilation Error).
- **استيراد فئات متضاربة**: في حالة وجود فئات بنفس الاسم في حزم مختلفة، يجب استيراد الفئة المطلوبة بشكل محدد لتجنب أي لبس.

### ملاحظات إضافية
- لا يمكن استخدام عبارة "import" داخل الفئات أو بداخل الدوال، بل يجب أن تكون في أعلى الملف.
- يمكنك استخدام عبارات "import" متعددة في ملف واحد، لكن يجب عليك تنظيمها بشكل جيد لتسهيل القراءة.

## ملخص من جملة واحدة
عبارة "import" في جافا تسمح للمطورين باستيراد الحزم والفئات، مما يسهل استخدام الكود الخارجي ويعزز من كفاءة البرمجة.
