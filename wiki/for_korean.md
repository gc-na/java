# Java의 for 문: 반복 구조의 이해와 활용

## 개요
Java에서 `for` 문은 반복 작업을 수행하는 데 사용되는 제어 구조로, 특정 조건이 참인 동안 코드를 반복 실행합니다. 이 문은 주로 배열이나 컬렉션을 순회하거나 특정 횟수만큼 반복할 때 유용하게 사용됩니다.

## 문서화
### 목적
`for` 문은 코드 블록을 여러 번 실행할 수 있도록 하여, 프로그래머가 반복 작업을 간편하게 처리할 수 있게 합니다. 이를 통해 코드의 가독성을 높이고 중복을 줄일 수 있습니다.

### 사용법
Java에서 `for` 문은 다음과 같은 기본 구문을 가집니다:

```java
for (초기화; 조건; 증감) {
    // 반복할 코드 블록
}
```

- **초기화**: 반복 변수의 초기값을 설정합니다.
- **조건**: 반복을 계속할지 여부를 결정하는 논리식입니다. 조건이 `true`인 동안 반복이 계속됩니다.
- **증감**: 반복 변수를 증감시키는 표현식입니다.

### 세부 사항
- `for` 문은 다양한 타입의 반복 변수를 사용할 수 있으며, 주로 정수형 변수를 사용합니다.
- 조건이 처음부터 `false`일 경우, 반복문 내의 코드 블록은 한 번도 실행되지 않습니다.
- Java에서는 중첩된 `for` 문을 사용할 수 있으며, 이 경우 내부 반복문은 외부 반복문의 각 반복마다 실행됩니다.

## 예제
### 기본 사용 예제

```java
// 0부터 4까지의 숫자를 출력하는 예제
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

### 배열 순회 예제

```java
// 배열의 모든 요소를 출력하는 예제
String[] fruits = {"사과", "바나나", "오렌지"};
for (int i = 0; i < fruits.length; i++) {
    System.out.println(fruits[i]);
}
```

## 설명
`for` 문을 사용할 때 주의해야 할 몇 가지 사항이 있습니다:

- **무한 반복**: 조건이 항상 `true`인 경우 무한 반복에 빠질 수 있습니다. 이는 프로그램의 성능 저하나 충돌을 초래할 수 있습니다.
- **인덱스 범위 초과**: 배열이나 리스트의 길이를 초과하는 인덱스에 접근하면 `ArrayIndexOutOfBoundsException`이 발생합니다. 항상 조건을 적절하게 설정해야 합니다.
- **가독성**: 중첩된 `for` 문이 많아질 경우 코드의 가독성이 떨어질 수 있습니다. 이럴 때는 메서드를 분리하거나 다른 반복 구조를 사용하는 것이 좋습니다.

## 한 줄 요약
Java의 `for` 문은 특정 조건이 참인 동안 코드 블록을 반복 실행하여 효율적인 반복 작업을 가능하게 하는 제어 구조입니다.
