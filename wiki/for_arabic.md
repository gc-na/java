# استخدام جملة "for" في جافا: دليل شامل

## الملخص
جملة "for" هي واحدة من الهياكل الأساسية في لغة جافا، تُستخدم لتكرار تنفيذ مجموعة من التعليمات بشكل متكرر حتى يتحقق شرط معين.

## الوثائق
تُستخدم جملة "for" لتنفيذ حلقة تكرارية، مما يسمح للمطورين بتكرار كود معين لعدد محدد من المرات أو حتى يتحقق شرط معين. تتميز جملة "for" بكونها فعالة وسهلة الفهم، حيث تُعتبر مثالية عند معرفة عدد مرات التكرار مسبقًا. 

### الصيغة العامة
```java
for (initialization; termination; increment) {
    // الكود الذي سيتم تنفيذه في كل تكرار
}
```

- **initialization**: تُستخدم لتهيئة متغيرات الحلقة.
- **termination**: شرط يُستخدم لتحديد متى يجب إنهاء الحلقة.
- **increment**: يُستخدم لتحديث المتغيرات في كل تكرار.

### الاستخدام
يمكن استخدام جملة "for" مع أي نوع من البيانات القابلة للتكرار، كما أنها تدعم التكرار على مصفوفات أو قوائم أو أي مجموعة أخرى.

## الأمثلة

### مثال 1: حلقة بسيطة
```java
for (int i = 0; i < 5; i++) {
    System.out.println("العدد هو: " + i);
}
```
هذا المثال سيقوم بطباعة الأعداد من 0 إلى 4.

### مثال 2: حلقة للتكرار عبر مصفوفة
```java
String[] fruits = {"تفاح", "موز", "برتقال"};
for (int i = 0; i < fruits.length; i++) {
    System.out.println("الفاكهة: " + fruits[i]);
}
```
هذا المثال يقوم بتكرار كل عنصر في مصفوفة الفواكه.

## الشرح
### الفخاخ الشائعة
- **عدم تحديث المتغير**: إذا نسيت تحديث المتغير في جملة "increment"، ستدخل الحلقة في حلقة لا نهائية.
- **الشرط الخاطئ**: تأكد من أن شرط الإنهاء صحيح، فشرط غير صحيح سيؤدي إلى عدم إنهاء الحلقة.

### ملاحظات إضافية
- يمكن استخدام جملة "for" بشكل متداخل (حلقات داخل حلقات) لتكرار مجموعات متعددة.
- من الممكن استخدام `for-each` للتكرار على عناصر مجموعة بدون الحاجة إلى استخدام العدادات.

## ملخص جملة واحدة
جملة "for" في جافا هي هيكل تحكم يُستخدم لتكرار تنفيذ مجموعة من التعليمات حتى يتحقق شرط معين، مما يوفر طريقة فعالة لتنفيذ العمليات المتكررة.
