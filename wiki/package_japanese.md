# Javaにおける「パッケージ」: 概要と使い方

## 概要
Javaの「パッケージ」は、クラスやインターフェースを整理し、名前の衝突を避けるための機能です。パッケージを使用することで、プログラムの構造を明確にし、管理しやすくすることができます。

## ドキュメンテーション
### 目的
Javaのパッケージは、関連するクラスやインターフェースをグループ化するための手段です。これにより、コードのモジュール化が進み、再利用性が向上します。また、パッケージはクラスの名前空間を提供し、同じ名前のクラスが異なるパッケージ内で共存できるようにします。

### 使用法
Javaのパッケージを定義するには、クラス定義の先頭に`package`キーワードを使用します。例えば、次のように記述します。

```java
package com.example.myapp;
```

この宣言により、`com.example.myapp`という名前のパッケージに所属するクラスが定義されます。

### 詳細
- **パッケージの作成**: Javaファイルを特定のディレクトリに配置し、そのファイル内で`package`宣言を行うことでパッケージを作成します。
- **インポート**: 他のパッケージのクラスを使用するには、`import`文を使います。例えば、`java.util.ArrayList`を使用する場合は、以下のように記述します。

```java
import java.util.ArrayList;
```

- **デフォルトパッケージ**: パッケージ宣言がないクラスはデフォルトパッケージに属しますが、これは推奨されていません。

## 例
以下は、パッケージを使用した簡単な例です。

```java
// MyClass.java
package com.example.myapp;

public class MyClass {
    public void display() {
        System.out.println("Hello from MyClass!");
    }
}

// Main.java
package com.example.myapp;

public class Main {
    public static void main(String[] args) {
        MyClass myObject = new MyClass();
        myObject.display();
    }
}
```

この例では、`MyClass`と`Main`の両方が同じパッケージに属しており、`MyClass`のインスタンスを`Main`から簡単に作成できます。

## 説明
### 一般的な落とし穴
- **名前の衝突**: 同じ名前のクラスが異なるパッケージに存在する場合、クラスを使用する際には完全修飾名を指定する必要があります。
- **デフォルトパッケージの使用**: デフォルトパッケージは、特に大規模なプロジェクトにおいては管理が難しくなるため、使用を避けるべきです。
- **インポートの不備**: 必要なクラスをインポートし忘れると、コンパイルエラーが発生します。
