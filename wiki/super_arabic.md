# استخدام الكلمة المفتاحية "super" في لغة جافا

## ملخص
الكلمة المفتاحية "super" في لغة جافا تستخدم للإشارة إلى الفئة العليا (Superclass) في سياق الوراثة. تسهل هذه الكلمة الوصول إلى المتغيرات والطرق الخاصة بالفئة الأم، مما يعزز من إمكانية إعادة استخدام الكود.

## الوثائق
### الغرض
تستخدم "super" لأغراض متعددة في جافا، منها:
- الوصول إلى الخصائص (fields) والطرق (methods) الخاصة بالفئة العليا.
- استدعاء الباني (constructor) للفئة العليا.

### الاستخدام
يمكن استخدام "super" في:
1. الإشارة إلى المتغيرات والطرق الخاصة بالفئة العليا:
   ```java
   super.methodName();
   super.variableName;
   ```

2. استدعاء الباني للفئة العليا:
   ```java
   super(parameter1, parameter2);
   ```

### التفاصيل
- عند استخدام "super" لاستدعاء طريقة من الفئة العليا، يجب أن تكون الطريقة غير مغطاة (overridden) في الفئة الفرعية.
- يمكن استخدام "super" فقط داخل الفئات الفرعية.

## أمثلة
### مثال 1: الوصول إلى طرق الفئة العليا
```java
class Parent {
    void display() {
        System.out.println("هذه طريقة من الفئة الأم.");
    }
}

class Child extends Parent {
    void display() {
        super.display(); // استدعاء طريقة الفئة العليا
        System.out.println("هذه طريقة من الفئة الفرعية.");
    }
}

public class Main {
    public static void main(String[] args) {
        Child child = new Child();
        child.display();
    }
}
```
**الإخراج:**
```
هذه طريقة من الفئة الأم.
هذه طريقة من الفئة الفرعية.
```

### مثال 2: استدعاء الباني للفئة العليا
```java
class Parent {
    Parent() {
        System.out.println("باني الفئة الأم.");
    }
}

class Child extends Parent {
    Child() {
        super(); // استدعاء باني الفئة العليا
        System.out.println("باني الفئة الفرعية.");
    }
}

public class Main {
    public static void main(String[] args) {
        Child child = new Child();
    }
}
```
**الإخراج:**
```
باني الفئة الأم.
باني الفئة الفرعية.
```

## الشرح
- **المشاكل الشائعة:** 
  - إذا حاولت استخدام "super" خارج الفئة الفرعية، ستحصل على خطأ في التجميع (compilation error).
  - يجب أن تكون الطرق أو المتغيرات التي تحاول الوصول إليها باستخدام "super" متاحة (accessible) من الفئة الفرعية.

- **ملاحظات إضافية:**
  - "super" لا يمكن استخدامها بشكل مباشر للوصول إلى الخصائص الخاصة بالفئة العليا إذا كانت محمية (protected) أو خاصة (private) إلا إذا كانت الفئة الفرعية داخل نفس الحزمة.

## ملخص جملة واحدة
الكلمة المفتاحية "super" في جافا تتيح الوصول إلى خصائص وطرق الفئة العليا، مما يسهل عملية الوراثة وإعادة استخدام الكود.
