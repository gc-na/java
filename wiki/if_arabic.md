# جملة "if" في لغة جافا: الاستخدامات والتفاصيل

## ملخص
جملة "if" في لغة جافا هي عبارة شرطية تتيح للمطورين اتخاذ قرارات في الشيفرة البرمجية بناءً على شروط معينة. تعتبر هذه الجملة من العناصر الأساسية في البرمجة الشرطية.

## الوثائق
### الغرض
تستخدم جملة "if" لتحديد مسار التنفيذ في البرنامج بناءً على تقييم تعبير منطقي. إذا كان التعبير صحيحًا (true)، يتم تنفيذ الكود داخل كتلة "if"، وإذا كان خاطئًا (false)، يتم تخطي هذه الكتلة.

### الاستخدام
تستخدم جملة "if" في سياقات متعددة، ويمكن استخدامها بالشكل التالي:
```java
if (شرط) {
    // الكود الذي سيتم تنفيذه إذا كان الشرط صحيحًا
}
```

### التفاصيل
- **الشرط**: يجب أن يكون تعبيرًا منطقيًا (boolean) يعيد القيمة true أو false.
- **كتلة الكود**: يمكن أن تحتوي على أكثر من سطر من الشيفرة، وفي حالة وجود سطر واحد يمكن الاستغناء عن الأقواس {}.
- **جملة if-else**: يمكن استخدام "else" لتحديد الكود الذي سيتم تنفيذه إذا كان الشرط خاطئًا:

```java
if (شرط) {
    // الكود إذا كان الشرط صحيحًا
} else {
    // الكود إذا كان الشرط خاطئًا
}
```

- **if-else if-else**: يمكن استخدام سلسلة من الشروط مع "else if" لتقييم شروط متعددة:

```java
if (شرط1) {
    // الكود إذا كان الشرط1 صحيحًا
} else if (شرط2) {
    // الكود إذا كان الشرط2 صحيحًا
} else {
    // الكود إذا لم يكن أي من الشروط صحيحًا
}
```

## أمثلة
### مثال بسيط
```java
int عدد = 10;
if (عدد > 5) {
    System.out.println("العدد أكبر من 5");
}
```

### مثال مع else
```java
int عدد = 3;
if (عدد > 5) {
    System.out.println("العدد أكبر من 5");
} else {
    System.out.println("العدد ليس أكبر من 5");
}
```

### مثال with else if
```java
int عدد = 5;
if (عدد > 5) {
    System.out.println("العدد أكبر من 5");
} else if (عدد == 5) {
    System.out.println("العدد يساوي 5");
} else {
    System.out.println("العدد أصغر من 5");
}
```

## الشرح
### الأخطاء الشائعة
- **نسيان الأقواس**: عند استخدام جملة "if" مع أكثر من سطر، يجب دائمًا استخدام الأقواس {} لتجنب الأخطاء.
- **تقييمات خاطئة**: تأكد من أن التعبيرات المنطقية تعيد القيم الصحيحة؛ قد يؤدي استخدام العمليات الخاطئة إلى سلوك غير متوقع.
- **الاعتماد على القيم الافتراضية**: عند استخدام جملة "if" على كائنات، تأكد من أن الكائنات ليست null لتجنب NullPointerException.

## ملخص جملة واحدة
جملة "if" في جافا هي أداة أساسية لتنفيذ الكود بناءً على تقييم شروط منطقية، مما يسمح بإنشاء برنامج ديناميكي يستجيب لمتطلبات معينة.
