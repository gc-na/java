# البوليان (boolean) في جافا: التعريف، الاستخدامات والأمثلة

## ملخص
البوليان (boolean) هو نوع بيانات في جافا يُستخدم لتمثيل القيم الثنائية (صحيح أو خاطئ) والتي تلعب دورًا أساسيًا في التحكم في تدفق البرنامج.

## الوثائق
### الغرض
يستخدم نوع البيانات البوليان في جافا لتخزين قيمتين فقط: `true` (صحيح) و `false` (خاطئ). يتم استخدامه بشكل شائع في الشروط، الحلقات، والتعبيرات المنطقية.

### الاستخدام
يتم تعريف المتغيرات من نوع البوليان باستخدام الكلمة المفتاح `boolean`. يمكن أن تُستخدم هذه المتغيرات في عبارات التحكم مثل `if`, `while`, و `for`.

### التفاصيل
- **تعريف المتغيرات**: يمكنك تعريف متغير من نوع البوليان كما يلي:
  ```java
  boolean isActive = true;
  ```
- **العمليات المنطقية**: يمكن استخدام العمليات المنطقية مثل AND (`&&`)، OR (`||`)، NOT (`!`) لتكوين تعبيرات معقدة:
  ```java
  boolean isAdult = age >= 18;
  boolean canVote = isAdult && !isRestricted;
  ```
- **استخدام البوليان في الشروط**:
  ```java
  if (isActive) {
      System.out.println("الحساب نشط");
  } else {
      System.out.println("الحساب غير نشط");
  }
  ```

## الأمثلة
### مثال 1: استخدام البوليان في الشروط
```java
public class BooleanExample {
    public static void main(String[] args) {
        boolean isRaining = false;

        if (isRaining) {
            System.out.println("احضر مظلة");
        } else {
            System.out.println("الجو مشمس");
        }
    }
}
```

### مثال 2: العمليات المنطقية
```java
public class LogicalOperations {
    public static void main(String[] args) {
        boolean hasPermission = true;
        boolean isAdmin = false;

        if (hasPermission && isAdmin) {
            System.out.println("يمكنك الوصول إلى محتوى الإدارة");
        } else {
            System.out.println("ليس لديك إذن للوصول");
        }
    }
}
```

## الشرح
### الفخاخ الشائعة
- **عدم التهيئة**: إذا حاولت استخدام متغير بولياني دون تهيئته، ستظهر لك رسالة خطأ.
- **تداخل الشروط**: قد يكون من الصعب تتبع النتائج عندما تحتوي الشروط على عمليات منطقية متعددة.
- **استخدام القيم غير الصحيحة**: تذكر أن القيم الوحيدة المسموح بها هي `true` و `false`.

### ملاحظات إضافية
- عند مقارنة المتغيرات البوليانية، تأكد من استخدام التعبيرات الصحيحة لأن المقارنات الخاطئة قد تؤدي إلى نتائج غير متوقعة.
- يُفضل استخدام الأسماء الواضحة للمتغيرات البوليانية لتسهيل قراءة الكود وفهمه.

## ملخص الجملة
البوليان في جافا هو نوع بيانات يمثل القيم الثنائية (صحيح أو خاطئ) ويستخدم بشكل واسع في التحكم في تدفق البرنامج.
