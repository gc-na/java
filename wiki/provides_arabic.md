# يوفر (provides) في جافا: فهم المفهوم واستخداماته

## ملخص
في جافا، كلمة "يوفر" (provides) تشير إلى مفهوم الاستخدام في سياق خدمات التوزيع (modular programming) وإدارة التبعيات. يُستخدم هذا المصطلح بشكل خاص في النظام الجديد لـ Java Platform Module System (JPMS)، الذي تم تقديمه في Java 9.

## الوثائق
تُستخدم كلمة "يوفر" في جافا لتحديد ما تقدمه وحدة معينة من خدمات أو واجهات لمكونات أخرى. يوفر النظام الوحدوي في جافا طريقة لتنظيم الكود وتقليل التبعيات غير الضرورية بين الوحدات. يتم الإعلان عن الخدمات التي تقدمها الوحدة من خلال ملف وصف الوحدة `module-info.java`.

### الغرض
الغرض من استخدام "يوفر" هو تحديد ما يمكن للوحدة تقديمه للآخرين، مما يجعل الكود أكثر تنظيماً وسهولة في الصيانة والاستخدام.

### الاستخدام
تُستخدم كلمة "يوفر" في جافا بالطريقة التالية:

```java
module اسم_الوحدة {
    provides واجهة_معينة with تنفيذ_معين;
}
```

### التفاصيل
- **الوحدات**: الوحدات هي وحدات مستقلة من الكود التي يمكن أن تحتوي على صفوف وواجهات ومكتبات.
- **واجهات**: الواجهة هي مجموعة من الطرق التي يمكن استخدامها بواسطة الوحدات الأخرى.
- **تنفيذ**: يمثل الكائن أو الصف الذي ينفذ الواجهة المحددة.

## الأمثلة
### مثال 1: استخدام كلمة "يوفر"
```java
module my.module {
    provides my.package.MyService with my.package.MyServiceImpl;
}
```
في هذا المثال، يتم تعريف وحدة `my.module` التي توفر خدمة `MyService` باستخدام التنفيذ `MyServiceImpl`.

### مثال 2: استهلاك الخدمة
```java
import my.package.MyService;

public class Client {
    private MyService myService;

    public Client(MyService myService) {
        this.myService = myService;
    }
}
```
يظهر هذا المثال كيف يمكن لوحدة أخرى استخدام الخدمة المقدمة.

## الشرح
### الأخطاء الشائعة
- **نسيان إضافة مكتبة في `module-info.java`**: يجب التأكد من أن جميع المكتبات المطلوبة موجودة.
- **خلط بين `requires` و`provides`**: `requires` يُستخدم لتحديد التبعيات، بينما `provides` يُستخدم لتحديد الخدمات المقدمة.

### ملاحظات إضافية
- من المهم توخي الحذر في إدارة الوحدات والخدمات، حيث يمكن أن يؤدي سوء الاستخدام إلى تعقيد الكود.
- يجب أن تكون هناك توافق بين الواجهات والتطبيقات المستخدمة لتجنب الأخطاء.

## ملخص بجملة واحدة
تستخدم كلمة "يوفر" في جافا للإشارة إلى الخدمات التي تقدمها الوحدات، مما يسهل إدارة التبعيات وتنظيم الكود.
