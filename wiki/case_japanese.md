# Javaにおける「case」文の使い方

## 概要
Javaにおける「case」は、switch文の一部として使用されるキーワードであり、特定の条件に基づいて異なるコードブロックを実行するための制御構造です。このキーワードは、プログラムの流れを制御するために非常に便利です。

## ドキュメンテーション
### 目的
「case」文は、switch文の構成要素であり、特定の値に一致する場合に実行されるコードブロックを定義します。複数の条件を簡潔に処理できるため、複雑なif文の代替としてよく使用されます。

### 使用法
switch文を使用する際、次のような構文で「case」を使用します。

```java
switch (式) {
    case 値1:
        // 値1に一致する場合の処理
        break;
    case 値2:
        // 値2に一致する場合の処理
        break;
    default:
        // どのcaseにも一致しない場合の処理
}
```

### 詳細
- **式**: switch文で評価される値。整数型、文字型、列挙型、文字列型が使用可能です。
- **case**: 各caseは、switchで評価された値がこの値と一致する場合に実行されるコードを指定します。
- **break**: 各caseの終わりには通常、break文が必要です。これにより、switch文から脱出し、次の処理に進みます。
- **default**: どのcaseにも一致しない場合に実行されるコードブロックを定義します。省略可能ですが、指定しておくと安全です。

## 例
以下は、Javaのswitch文とcase文を使用した基本的な例です。

```java
int day = 3;
String dayName;

switch (day) {
    case 1:
        dayName = "月曜日";
        break;
    case 2:
        dayName = "火曜日";
        break;
    case 3:
        dayName = "水曜日";
        break;
    case 4:
        dayName = "木曜日";
        break;
    case 5:
        dayName = "金曜日";
        break;
    default:
        dayName = "週末";
}

System.out.println(dayName); // 出力: 水曜日
```

## 説明
- **共通の落とし穴**: case文の最後にbreakを忘れると、次のcase文も実行されてしまうことがあります。これを「フォールスルー」と呼びます。意図的に使用する場合を除き、break文を忘れないようにしましょう。
- **型の制限**: switch文は整数型、文字型、列挙型、文字列型のみに使用できます。浮動小数点数やオブジェクトには適用できません。
- **デフォルトケース**: defaultブロックを使用することで、予期しない値に対するエラーハンドリングが可能です。
