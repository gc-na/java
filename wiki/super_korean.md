# JAVA에서 "super" 키워드 이해하기

## 개요
"super"는 JAVA에서 부모 클래스의 필드와 메서드에 접근할 수 있도록 돕는 키워드입니다. 이 키워드는 주로 상속 관계에서 자식 클래스가 부모 클래스의 기능을 재사용하거나, 부모 클래스를 명시적으로 호출할 때 사용됩니다.

## 문서화
"super" 키워드는 JAVA 프로그래밍 언어에서 상속을 지원하는 중요한 요소입니다. 자식 클래스는 부모 클래스의 속성과 메서드를 상속받지만, 때때로 부모 클래스의 특정 속성이나 메서드에 직접 접근해야 할 필요가 있습니다. 이때 "super" 키워드를 사용하여 부모 클래스의 멤버에 접근할 수 있습니다.

### 사용 목적
- 부모 클래스의 생성자 호출: 자식 클래스의 생성자에서 부모 클래스의 생성자를 호출할 때 사용됩니다.
- 부모 클래스의 메서드 호출: 자식 클래스에서 부모 클래스의 메서드를 오버라이드하더라도 부모 클래스의 원래 메서드를 호출할 수 있습니다.
- 부모 클래스의 필드 접근: 자식 클래스에서 부모 클래스의 필드를 직접 참조할 수 있습니다.

### 사용법
"super" 키워드는 다음과 같은 방식으로 사용됩니다:
1. **부모 클래스 생성자 호출**: `super();`
2. **부모 클래스 메서드 호출**: `super.methodName();`
3. **부모 클래스 필드 접근**: `super.fieldName;`

## 예제
```java
class Parent {
    String name = "부모";

    Parent() {
        System.out.println("부모 클래스의 생성자");
    }

    void display() {
        System.out.println("부모 클래스의 메서드");
    }
}

class Child extends Parent {
    String name = "자식";

    Child() {
        super(); // 부모 클래스의 생성자 호출
        System.out.println("자식 클래스의 생성자");
    }

    void display() {
        super.display(); // 부모 클래스의 메서드 호출
        System.out.println("자식 클래스의 메서드");
    }

    void showNames() {
        System.out.println("부모 이름: " + super.name); // 부모 클래스의 필드 접근
        System.out.println("자식 이름: " + this.name);
    }
}

public class Main {
    public static void main(String[] args) {
        Child child = new Child();
        child.display();
        child.showNames();
    }
}
```

## 설명
"super" 키워드를 사용할 때 발생할 수 있는 일반적인 오류나 주의사항은 다음과 같습니다:

- **생성자 호출 순서**: "super()" 호출은 자식 클래스의 생성자에서 반드시 첫 줄에 위치해야 하며, 그렇지 않으면 컴파일 오류가 발생합니다.
- **메서드 오버라이딩**: 자식 클래스에서 부모 클래스의 메서드를 오버라이드할 경우, "super"를 사용하여 부모 클래스의 메서드를 명시적으로 호출해야 합니다.
- **필드 접근 우선순위**: 자식 클래스에서 부모 클래스와 동일한 이름의 필드를 정의한 경우, "super"를 사용하여 부모 클래스의 필드에 접근할 수 있습니다. 그렇지 않으면 자식 클래스의 필드가 우선적으로 참조됩니다.
