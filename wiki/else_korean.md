# Java의 else 문: 조건문 제어의 기초

## 개요
Java의 `else` 문은 조건문에서 특정 조건이 거짓일 경우 실행되는 코드를 정의하는 데 사용됩니다. `if` 문과 함께 사용되어 프로그램의 흐름을 제어하는 중요한 역할을 합니다.

## 문서화
`else` 문은 조건문에서 중요한 구성 요소로, `if` 문과 함께 사용하여 조건에 따라 서로 다른 코드 블록을 실행할 수 있습니다. 기본적인 문법은 다음과 같습니다:

```java
if (조건) {
    // 조건이 참일 때 실행되는 코드
} else {
    // 조건이 거짓일 때 실행되는 코드
}
```

이 구조를 통해 프로그래머는 프로그램의 흐름을 제어할 수 있으며, 여러 조건을 조합하여 복잡한 로직을 구현할 수 있습니다. `else` 문은 선택적이며, 필요에 따라 여러 개의 `if` 문과 함께 사용할 수 있습니다.

### 사용 예
`else` 문은 다음과 같이 사용됩니다:

```java
int number = 10;

if (number > 0) {
    System.out.println("양수입니다.");
} else {
    System.out.println("음수 또는 0입니다.");
}
```

위 코드에서 `number`가 0보다 클 경우 "양수입니다."가 출력되고, 그렇지 않을 경우 "음수 또는 0입니다."가 출력됩니다.

## 예제
다양한 조건을 처리하는 `if-else` 문 예제:

```java
int score = 85;

if (score >= 90) {
    System.out.println("A학점입니다.");
} else if (score >= 80) {
    System.out.println("B학점입니다.");
} else if (score >= 70) {
    System.out.println("C학점입니다.");
} else {
    System.out.println("D학점 이하입니다.");
}
```

이 예제에서 `score`에 따라 학점이 결정됩니다. `else if` 문을 통해 여러 조건을 처리할 수 있습니다.

## 설명
`else` 문을 사용할 때 주의할 점은 다음과 같습니다:

1. **조건의 순서**: `if` 문은 먼저 평가되고, 그 다음 `else` 문이 평가됩니다. 따라서 조건의 순서를 잘 설정해야 올바른 결과를 얻을 수 있습니다.
2. **중첩 사용**: `if` 문과 `else` 문을 중첩하여 사용할 수 있지만, 지나치게 복잡해지면 가독성이 떨어질 수 있습니다.
3. **문법 오류**: `else` 문은 항상 `if` 문에 이어서 사용해야 하며, 독립적으로 사용할 수 없습니다.

## 한 줄 요약
Java의 `else` 문은 조건이 거짓일 때 실행될 코드를 정의하여 프로그램의 흐름을 제어하는 데 중요한 역할을 한다.
