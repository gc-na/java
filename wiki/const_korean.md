# JAVA에서의 const 키워드: 사용법 및 특징

## 개요
JAVA 프로그래밍 언어에서 `const` 키워드는 상수를 정의하기 위해 사용되는 예약어이지만, JAVA에서는 실제로 사용되지 않습니다. JAVA는 상수를 정의하기 위해 `final` 키워드를 사용하며, 이 문서에서는 `const`의 의미와 상수 정의 방법에 대해 설명합니다.

## 문서화
### 목적
`const`는 JAVA에서 예약어로 존재하지만, 사용되지 않으며, JAVA에서 상수를 정의할 때는 `final` 키워드를 사용해야 합니다. 상수는 값이 변경되지 않는 변수를 의미하며, 프로그램의 안정성과 가독성을 높이는 데 기여합니다.

### 사용법
JAVA에서 상수를 정의할 때는 다음과 같이 `final` 키워드를 사용합니다:

```java
final int MAX_VALUE = 100;
```

여기서 `MAX_VALUE`는 변경할 수 없는 상수입니다. `final` 키워드는 변수 선언 시 한 번만 값을 할당할 수 있음을 뜻합니다. `const`는 JAVA에서 사용되지 않으므로, 개발자는 `final`을 사용하여 상수를 정의해야 합니다.

### 세부사항
- `final` 키워드로 정의된 변수는 초기화 후 값을 변경할 수 없습니다.
- 클래스, 메서드, 지역 변수 모두에 대해 `final`을 사용할 수 있습니다.
- 상수는 일반적으로 대문자로 정의하며, 여러 단어로 구성된 경우 언더스코어(_)로 구분합니다.

## 예제
다음은 JAVA에서 상수를 정의하고 사용하는 간단한 예제입니다:

```java
public class ConstantExample {
    public static final double PI = 3.14159;

    public static void main(String[] args) {
        System.out.println("원의 면적은 " + (PI * 5 * 5) + "입니다.");
    }
}
```

이 예제에서 `PI`는 원주율을 나타내는 상수로, 프로그램 내에서 변경할 수 없습니다.

## 설명
### 일반적인 함정 및 주의사항
- `const`는 JAVA에서 사용할 수 없으므로, 개발자가 혼동하지 않도록 주의해야 합니다.
- 상수를 정의할 때 `final` 키워드를 사용하는 것을 잊지 말고, 항상 초기화해야 합니다.
- 상수는 클래스 멤버로 정의할 때 `static`과 함께 사용되는 경우가 많습니다.

## 한 줄 요약
JAVA에서는 `const` 키워드를 사용하지 않으며, 상수는 `final` 키워드를 통해 정의됩니다.
