# استخدام جملة switch في لغة جافا

## ملخص
تُعد جملة `switch` في لغة جافا من الأدوات الأساسية للتحكم في تدفق التنفيذ بناءً على قيمة معينة. تُستخدم لتبسيط الشيفرات التي تحتوي على مجموعة من الشروط المتعددة.

## الوثائق
### الغرض
تُستخدم جملة `switch` لتحديد تنفيذ كود معين بناءً على قيمة تعبير ما. هي بديل مناسب لجملة `if-else` عندما يكون لديك عدد كبير من الشروط البسيطة.

### الاستخدام
تُكتب جملة `switch` بالشكل التالي:

```java
switch (expression) {
    case value1:
        // كود للتنفيذ إذا كانت القيمة تطابق value1
        break;
    case value2:
        // كود للتنفيذ إذا كانت القيمة تطابق value2
        break;
    // يمكن إضافة المزيد من الحالات
    default:
        // كود للتنفيذ إذا لم تطابق أي حالة
}
```

- **expression**: التعبير الذي يتم تقييمه، ويمكن أن يكون من نوع `int`, `char`, `String`, أو أي نوع بيانات آخر يدعمه جافا.
- **case**: كل حالة تمثل قيمة معينة يمكن أن تتطابق مع قيمة التعبير.
- **break**: تُستخدم للخروج من جملة `switch` بعد تنفيذ الكود الخاص بالحالة المطابقة. إذا تم حذفها، ستستمر عملية التنفيذ إلى الحالة التالية.
- **default**: حالة اختيارية تُستخدم عند عدم تطابق أي من الحالات السابقة.

## الأمثلة
### مثال 1: استخدام switch مع الأعداد الصحيحة

```java
int day = 3;
String dayName;

switch (day) {
    case 1:
        dayName = "الأحد";
        break;
    case 2:
        dayName = "الاثنين";
        break;
    case 3:
        dayName = "الثلاثاء";
        break;
    default:
        dayName = "يوم غير معروف";
}

System.out.println(dayName); // ستظهر "الثلاثاء"
```

### مثال 2: استخدام switch مع السلاسل النصية

```java
String fruit = "تفاح";
switch (fruit) {
    case "موز":
        System.out.println("موزة");
        break;
    case "تفاح":
        System.out.println("تفاح");
        break;
    default:
        System.out.println("فاكهة غير معروفة");
}
// ستظهر "تفاح"
```

## الشرح
### الأخطاء الشائعة
- **نسيان استخدام `break`**: إذا لم يتم استخدام `break`، ستستمر جملة `switch` في تنفيذ الكود الخاص بالحالات التالية حتى تصل إلى `break` أو نهاية الجملة.
- **استخدام أنواع بيانات غير مدعومة**: لا يمكن استخدام `switch` مع أنواع البيانات مثل `float` أو `double`.
- **عدم تضمين default**: من الأفضل دائمًا تضمين حالة `default` للتعامل مع الحالات غير المتوقعة.

## ملخص بسط
جملة `switch` في جافا هي أداة فعّالة للتحكم في تدفق البرنامج وفقًا لقيم متعددة بشكل منظم وسهل القراءة.
