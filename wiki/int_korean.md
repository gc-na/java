# Java의 데이터 타입: int

## 개요
Java에서 `int`는 정수를 표현하기 위한 기본 데이터 타입으로, 32비트 크기를 가지며 -2,147,483,648부터 2,147,483,647까지의 값을 저장할 수 있습니다. `int`는 주로 수치 계산 및 반복문, 배열 인덱스 등에서 널리 사용됩니다.

## 문서화
### 목적
`int` 데이터 타입은 Java 프로그래밍에서 정수를 처리하기 위한 가장 기본적인 방법으로, 메모리 사용 효율성이 높고 연산 속도가 빠른 특성을 가지고 있습니다. Java는 강타입 언어이기 때문에, `int` 타입의 변수는 반드시 정수 값을 가져야 하며, 다른 타입의 데이터와 혼합하여 사용할 경우 명시적인 형 변환이 필요합니다.

### 사용법
`int` 타입 변수를 선언하는 방법은 다음과 같습니다:

```java
int a; // 변수 a를 int 타입으로 선언
a = 10; // 변수 a에 10을 대입
```

`int` 타입 변수는 다음과 같이 선언과 동시에 초기화할 수 있습니다:

```java
int b = 20; // 변수 b를 선언하고 20으로 초기화
```

### 세부 사항
- **메모리 크기**: `int`는 4바이트(32비트)의 메모리를 소모합니다.
- **기본값**: 초기화되지 않은 `int` 타입 변수의 기본값은 0입니다.
- **범위**: `int` 타입은 -2,147,483,648에서 2,147,483,647까지의 값을 가질 수 있습니다.
- **형 변환**: 다른 숫자형 타입(예: `byte`, `short`, `long`)과의 연산 시, 자동 형 변환이 발생할 수 있습니다. 예를 들어, `int`와 `long`을 더할 경우 결과는 `long` 타입이 됩니다.

## 예제
### 기본 사용 예제
```java
public class IntExample {
    public static void main(String[] args) {
        int number = 100;
        System.out.println("정수 값: " + number);
    }
}
```

### 배열 인덱스
```java
public class ArrayExample {
    public static void main(String[] args) {
        int[] numbers = {1, 2, 3, 4, 5};
        for (int i = 0; i < numbers.length; i++) {
            System.out.println("인덱스 " + i + ": " + numbers[i]);
        }
    }
}
```

## 설명
`int` 변수 사용 시 주의할 점은 값의 범위를 초과하지 않도록 하는 것이며, 오버플로우가 발생할 수 있습니다. 예를 들어, `int` 타입의 최대값에 1을 더하면 음수로 돌아가는 현상이 발생할 수 있습니다. 또한, `int`를 사용하는 연산에서 `double`이나 `float` 타입과의 혼합 사용 시, 명시적 형 변환이 필요합니다.

## 한 줄 요약
Java에서 `int`는 32비트 정수를 표현하는 기본 데이터 타입으로, 수치 계산 및 다양한 프로그래밍 작업에 널리 사용된다.
