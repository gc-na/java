# مفهوم "abstract" في لغة JAVA

## ملخص
الـ "abstract" في لغة JAVA هي كلمة محجوزة تستخدم لتعريف الفئات والطرق التي لا تحتوي على تنفيذ كامل. وتعتبر طريقة فعالة لتنظيم الكود وتحقيق مفهوم الوراثة في البرمجة الشيئية.

## الوثائق
تستخدم الكلمة المحجوزة "abstract" في JAVA لتعريف الفئات المجردة (abstract classes) والطرق المجردة (abstract methods). الفئة المجردة هي فئة لا يمكن إنشاء كائنات منها، ولكن يمكن أن تحتوي على طرق مجرّدة وطرق عادية. والطرق المجردة هي طرق لا تتضمن تنفيذ، ويجب على الفئات المشتقة منها أن تقدم تنفيذًا لها.

### الغرض
الغرض من استخدام "abstract" هو توفير هيكل أساسي للفئات التي تعتمد على سلوكيات معينة، مما يسمح بتقليل التكرار وتعزيز إعادة الاستخدام للكود.

### الاستخدام
- **فئة مجردة**: يتم تعريف الفئة المجردة باستخدام الكلمة المحجوزة "abstract" قبل كلمة "class".
- **طريقة مجردة**: يتم تعريف الطريقة المجردة داخل الفئة المجردة باستخدام الكلمة "abstract" قبل نوع الإرجاع واسم الطريقة.

## الأمثلة

### مثال على فئة مجردة
```java
abstract class Animal {
    abstract void sound(); // طريقة مجردة

    void sleep() { // طريقة عادية
        System.out.println("Animal is sleeping");
    }
}
```

### مثال على فئة مشتقة
```java
class Dog extends Animal {
    void sound() {
        System.out.println("Bark");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.sound(); // سيعرض "Bark"
        dog.sleep(); // سيعرض "Animal is sleeping"
    }
}
```

## الشرح
من المهم أن نفهم أن الفئات المجردة لا يمكن أن تُستخدم لإنشاء كائنات مباشرة. عند محاولة إنشاء كائن من فئة مجردة، سيؤدي ذلك إلى حدوث خطأ في وقت التجميع. كما يجب أن تحتوي الفئات التي ترث من الفئات المجردة على تنفيذ للطرق المجردة، وإلا ستظل هي أيضًا فئات مجرّدة. 

### الأخطاء الشائعة
1. **محاولة إنشاء كائن من فئة مجردة**: سيؤدي ذلك إلى خطأ في وقت التجميع.
2. **عدم تنفيذ الطرق المجردة في الفئات المشتقة**: إذا لم تقم الفئة المشتقة بتنفيذ جميع الطرق المجردة، ستظل فئة مجردة.

## ملخص قصير
الكلمة المحجوزة "abstract" في JAVA تُستخدم لتعريف الفئات والطرق المجردة، مما يسهل تنظيم الكود وتعزيز الوراثة.
