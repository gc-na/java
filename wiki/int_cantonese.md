# JAVA 中的 int 數據類型：基礎介紹與使用指南

## 概述
在 JAVA 編程語言中，`int` 是一種基本數據類型，用於存儲整數值。它是 JAVA 中最常用的整數類型，因為其範圍足以滿足大多數應用需求，並且操作速度快。

## 文檔
### 目的
`int` 類型主要用於表示整數數據，無論是在數學計算、數據處理還是控制結構中，`int` 都是不可或缺的。

### 使用方法
在 JAVA 中，`int` 的宣告和使用非常簡單。基本語法如下：
```java
int variableName;
```
您可以在宣告的同時賦值：
```java
int number = 10;
```

### 詳細信息
- **範圍**：`int` 可以存儲的值範圍是從 -2,147,483,648 到 2,147,483,647，這是由於其佔用 4 字節（32 位）內存。
- **默認值**：對於未初始化的 `int` 變量，其默認值為 0。
- **運算符支持**：`int` 類型支持所有常見的數學運算符（如 +、-、*、/、%）以及增量運算符（++ 和 --）。

## 範例
以下是一些使用 `int` 的基本範例：

1. 宣告整數變量並賦值：
   ```java
   int age = 25;
   ```

2. 數學運算：
   ```java
   int a = 5;
   int b = 10;
   int sum = a + b; // sum 的值為 15
   ```

3. 使用條件語句：
   ```java
   int score = 85;
   if (score >= 60) {
       System.out.println("及格");
   } else {
       System.out.println("不及格");
   }
   ```

## 解釋
### 常見陷阱與注意事項
- **溢出**：當 `int` 的計算結果超過其範圍時，會發生溢出，導致不可預測的結果。例如：
  ```java
  int maxInt = Integer.MAX_VALUE; // 2147483647
  int overflow = maxInt + 1; // overflow 的值將是 -2147483648
  ```
  
- **整數除法**：在整數運算中，若兩個整數相除，結果仍為整數，且會舍去小數部分。例如：
  ```java
  int result = 5 / 2; // result 的值為 2，而非 2.5
  ```

- **類型轉換**：在進行數學運算時，若參與運算的變量類型不同，可能需要進行類型轉換，以避免潛在的錯誤。

## 一句總結
`int` 是 JAVA 中用於表示整數的基本數據類型，範圍廣泛且操作簡便，適合用於各種計算和數據處理場景。
