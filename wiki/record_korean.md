# 자바의 레코드 (Record) - 간결하고 효율적인 데이터 전송 객체

## 개요
자바의 레코드(Record)는 자바 14에서 미리보기 기능으로 도입되었으며, 자바 16에서 정식으로 발표된 기능으로, 데이터 전송 객체(DTO)를 보다 간결하고 명확하게 정의할 수 있도록 도와준다. 레코드는 불변성을 제공하며, 필드와 메서드를 자동으로 생성하여 코드의 가독성을 높인다.

## 문서화
레코드는 자바에서 데이터 모델을 정의하는 새로운 방법으로, 클래스의 복잡성을 줄이고 데이터 중심 애플리케이션을 더욱 효율적으로 작성할 수 있게 해준다. 레코드는 다음과 같은 주요 특징을 가진다:

1. **불변성**: 레코스의 필드는 생성 시에만 설정할 수 있으며, 이후에는 수정할 수 없다.
2. **자동 생성**: 레코드를 정의하면, equals(), hashCode(), toString() 메서드가 자동으로 생성된다.
3. **간결한 문법**: 레코드는 클래스를 정의하는 것보다 훨씬 간단한 구문으로 작성할 수 있다.

### 사용법
레코드는 `record` 키워드를 사용하여 정의한다. 기본적인 구문은 다음과 같다:

```java
public record RecordName(Type fieldName1, Type fieldName2) { }
```

여기서 `RecordName`은 레코드의 이름이고, `fieldName1`, `fieldName2`는 필드의 이름이다.

## 예제
레코드를 사용하는 간단한 예제는 다음과 같다:

```java
public record Person(String name, int age) { }

public class Main {
    public static void main(String[] args) {
        Person person = new Person("John", 30);
        System.out.println(person.name()); // John
        System.out.println(person.age());  // 30
        System.out.println(person);         // Person[name=John, age=30]
    }
}
```

위 예제에서 `Person` 레코드는 두 개의 필드 `name`과 `age`를 가지며, 이 필드들은 생성자를 통해 초기화된다. 또한, 자동으로 생성된 메서드를 통해 필드의 값을 쉽게 접근할 수 있다.

## 설명
레코드를 사용할 때 주의해야 할 점은 다음과 같다:

1. **불변성**: 레코스의 필드는 수정할 수 없으므로, 초기화 시에 모든 값을 올바르게 설정해야 한다.
2. **상속 제한**: 레코드는 다른 클래스를 상속받을 수 없으며, 다른 레코드나 클래스를 상속할 수 없다.
3. **다중 레코드 정의 불가**: 레코드는 하나의 레코드만 정의할 수 있으며, 다른 메서드나 필드를 추가할 수 없다.

레코드는 데이터 중심의 애플리케이션에서 유용하지만, 복잡한 비즈니스 로직을 포함한 객체에는 적합하지 않을 수 있다.

## 한 줄 요약
자바의 레코드는 간결하고 불변의 데이터 전송 객체를 정의하기 위한 새로운 방법으로, 자동으로 메서드를 생성하여 코드의 가독성을 향상시킨다.
