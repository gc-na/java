# Java 中的 "short" 數據類型概述

## 簡介
Java 中的 "short" 是一種基本數據類型，用於存儲較小範圍的整數值。它佔用 2 個字節（16 位），適合用於節省內存的情況。

## 文檔
### 目的
"short" 類型的主要目的是提供一種能夠儲存 -32,768 到 32,767 範圍內的整數值的方式，這對於需要節省內存的應用程式尤其重要。

### 使用方法
在 Java 中，"short" 可以通過關鍵字 `short` 來聲明。其基本語法如下：
```java
short variableName;
```
這樣就可以創建一個名為 `variableName` 的 short 變數。

### 詳細信息
- **範圍**: `-32,768` 到 `32,767`
- **佔用內存**: 2 個字節
- **預設值**: 0
- **包裝類**: `Short` 是 `short` 的包裝類，提供了對基本數據類型的額外功能。

## 示例
以下是使用 "short" 類型的基本示例：

```java
public class ShortExample {
    public static void main(String[] args) {
        short a = 1000;
        short b = 2000;
        short sum = (short) (a + b); // 使用類型轉換
        System.out.println("Sum: " + sum);
    }
}
```

## 解釋
- **常見陷阱**: 使用 "short" 時，注意運算的結果可能會超出範圍。例如，兩個 "short" 相加的結果可能會超過 32,767，這需要進行類型轉換，以避免類型不匹配的錯誤。
- **性能考量**: 雖然 "short" 可以節省內存，但在某些情況下，使用整數（`int`）可能會更有效，因為大多數現代處理器對於 32 位整數的操作優化更好。

## 一句總結
"short" 是 Java 中一種佔用 2 個字節的整數類型，專為需要節省內存的情況設計。
