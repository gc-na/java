# استخدام الكلمة المفتاحية "var" في لغة JAVA

## الملخص
تستخدم الكلمة المفتاحية "var" في لغة JAVA لتحديد المتغيرات بطريقة مختصرة، مما يسهل كتابة الشيفرات ويزيد من وضوحها.

## الوثائق
### الغرض
تم introduit الكلمة المفتاحية "var" في JAVA 10، وتسمح للمطورين بإنشاء متغيرات مع نوع بيانات يتم تحديده تلقائيًا بناءً على القيمة المعطاة. هذه الميزة تعزز قابلية القراءة وتقلل من التكرار.

### الاستخدام
يمكن استخدام "var" فقط في سياق متغيرات المحلية (local variables) داخل طريقة أو كتلة. يجب أن يتم تهيئة المتغير عند إنشائه، ولا يمكن استخدامه لتحديد المتغيرات على مستوى الفئة أو المتغيرات الثابتة.

### التفاصيل
- يجب تهيئة المتغيرات التي تستخدم "var" في نفس السطر.
- لا يمكن استخدام "var" مع الأنماط العامة (generic types) في التعريفات.
- لا يمكن استخدام "var" كنوع إرجاع في طرق.

## الأمثلة
### مثال بسيط
```java
var number = 10;  // يتم تحديد number كـ int
var name = "Java"; // يتم تحديد name كـ String
```

### مثال مع قائمة
```java
var numbersList = List.of(1, 2, 3, 4, 5); // يتم تحديد numbersList كـ List<Integer>
```

## الشرح
### الأخطاء الشائعة
- استخدام "var" دون تهيئة: لا يمكنك استخدام "var" بدون إعطائه قيمة، مثل:
  ```java
  var x; // هذا غير صحيح
  ```
  
- استخدام "var" مع الأنماط العامة: لا يمكن استخدام "var" في تعريفات الأنماط العامة:
  ```java
  var myList = new ArrayList<>(); // هذا صحيح، لكن
  var myList = new ArrayList<String>(); // هذا غير صحيح
  ```

### ملاحظات إضافية
- لا يمكن استخدام "var" في المتغيرات العالمية أو الثوابت.
- يفضل استخدام "var" عندما يكون نوع المتغير واضحًا من السياق لتجنب أي لبس.

## ملخص مختصر
تُستخدم الكلمة المفتاحية "var" في JAVA لتحديد متغيرات محلية بطريقة مختصرة، مما يحسن من وضوح الشيفرة البرمجية.
