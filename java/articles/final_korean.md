# Java의 final 키워드: 불변성과 성능 최적화

## 개요
Java에서 `final` 키워드는 변수, 메소드, 클래스에 적용될 수 있으며, 주로 불변성을 보장하고 성능을 최적화하는 데 사용됩니다. 이 키워드는 선언된 요소의 재정의를 방지하여, 코드의 안정성과 신뢰성을 높이는 데 기여합니다.

## 문서화

### 목적
`final` 키워드는 다음과 같이 세 가지 주요 용도로 사용됩니다:
1. **변수**: `final`로 선언된 변수는 초기화 후 변경할 수 없습니다. 이로 인해 상수 값을 정의할 수 있습니다.
2. **메소드**: `final` 메소드는 서브클래스에서 오버라이드할 수 없으므로, 특정 기능을 보호하는 데 사용됩니다.
3. **클래스**: `final` 클래스를 선언하면 해당 클래스를 상속할 수 없으므로, 클래스의 구조를 변경할 수 없습니다.

### 사용법
- **변수**: `final` 변수를 선언할 때는 반드시 초기화해야 하며, 이후에는 값을 변경할 수 없습니다.
- **메소드**: 메소드의 선언에 `final` 키워드를 추가하면, 해당 메소드는 서브클래스에서 재정의할 수 없습니다.
- **클래스**: 클래스 선언 앞에 `final`을 붙이면, 해당 클래스는 더 이상 상속될 수 없습니다.

### 세부사항
`final` 키워드는 다음과 같이 사용됩니다:

1. **변수**
   ```java
   final int MAX_VALUE = 100;
   ```
   이 변수는 이후에 값을 변경할 수 없습니다.

2. **메소드**
   ```java
   final void display() {
       System.out.println("This is a final method.");
   }
   ```
   이 메소드는 서브클래스에서 오버라이드할 수 없습니다.

3. **클래스**
   ```java
   final class MyClass {
       // 클래스 내용
   }
   ```
   이 클래스는 다른 클래스에서 상속될 수 없습니다.

## 예제
```java
// final 변수 예제
final int CONSTANT = 10;

// final 메소드 예제
class Base {
    final void show() {
        System.out.println("Final method in Base class.");
    }
}

class Derived extends Base {
    // 아래 코드는 오류를 발생시킵니다.
    // void show() { 
    //     System.out.println("Trying to override.");
    // }
}

// final 클래스 예제
final class FinalClass {
    // 클래스 내용
}
```

## 설명
`final` 키워드를 사용할 때 주의해야 할 몇 가지 사항이 있습니다:
- `final` 변수를 초기화하지 않으면 컴파일 오류가 발생합니다.
- `final` 메소드를 오버라이드하려고 시도하면 컴파일 오류가 발생합니다.
- `final` 클래스를 상속하려고 하면, 마찬가지로 컴파일 오류가 발생합니다.
- `final` 변수가 객체 참조일 경우, 객체의 내부 상태는 변경 가능하므로 주의가 필요합니다.

## 한 줄 요약
Java의 `final` 키워드는 변수, 메소드, 클래스를 불변으로 만들고, 코드의 안정성을 높이는 데 중요한 역할을 합니다.
