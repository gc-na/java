# JAVA의 var 키워드: 타입 추론의 혁신

## 개요
JAVA의 `var` 키워드는 자바 10에서 도입된 타입 추론 기능으로, 변수 선언 시 명시적으로 타입을 지정하지 않고도 컴파일러가 타입을 자동으로 추론할 수 있도록 합니다. 이로 인해 코드의 가독성이 향상되고, 코드 작성 시 불필요한 반복을 줄일 수 있습니다.

## 문서화
`var` 키워드는 자바의 지역 변수에만 사용되며, 메서드 내에서 변수 선언 시 활용됩니다. `var`를 사용하면 변수의 타입을 명시하지 않아도 컴파일러가 초기값을 바탕으로 타입을 결정합니다. 이는 특히 복잡한 제네릭 타입을 사용할 때 유용합니다.

### 사용법
`var`는 다음과 같은 방식으로 사용됩니다:
```java
var variableName = initialValue;
```
여기서 `variableName`은 변수의 이름이며, `initialValue`는 변수에 할당할 값입니다. 주의할 점은, `var`는 반드시 초기값과 함께 사용해야 하며, 타입이 명확하게 추론될 수 있어야 합니다.

### 세부 사항
- `var`는 오직 지역 변수 선언에만 사용 가능하며, 클래스 필드나 매개변수, 반환 타입에는 사용할 수 없습니다.
- `var`로 선언된 변수는 한 번 초기화되면 그 타입이 고정됩니다. 이후 타입을 변경할 수 없습니다.
- `var`를 사용할 때는 타입 추론이 불가능한 경우(예: 초기값이 null인 경우)에는 컴파일 오류가 발생합니다.
- `var`는 코드의 가독성을 높이지만, 남용할 경우 코드의 이해도를 떨어뜨릴 수 있으므로 적절히 사용해야 합니다.

## 예제
### 기본 사용 예
```java
var number = 10; // 타입은 int로 추론됩니다.
var name = "JAVA"; // 타입은 String으로 추론됩니다.
var list = new ArrayList<String>(); // 타입은 ArrayList<String>으로 추론됩니다.
```

### 복잡한 제네릭 타입 예
```java
var map = new HashMap<String, List<Integer>>(); // 복잡한 제네릭 타입도 var로 선언 가능합니다.
```

## 설명
`var` 사용 시 주의해야 할 몇 가지 사항이 있습니다. 예를 들어, `var`로 선언된 변수가 null로 초기화되면, 컴파일러는 타입을 추론할 수 없어 오류가 발생합니다. 또, 복잡한 타입의 경우, `var`를 사용함으로써 타입이 명확하지 않게 될 수 있으므로, 코드의 가독성을 위해 적절한 주석을 추가하는 것이 좋습니다.

또한, `var`는 자바의 기존 타입 선언 방식과 병행하여 사용될 수 있으므로, 개발자의 선호에 따라 선택적으로 적용할 수 있습니다.

## 요약
`var` 키워드는 자바에서 타입 추론을 가능하게 하여 코드 작성 시의 효율성을 높이고 가독성을 향상시키는 기능입니다.
