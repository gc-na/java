# Javaにおける「implements」：インターフェースの実装

## 概要
Javaの「implements」は、クラスがインターフェースを実装する際に使用されるキーワードです。この機能により、クラスはインターフェースで定義されたメソッドを具体的に実装することができます。

## ドキュメンテーション
### 目的
「implements」は、クラスがインターフェースに定義されたメソッドを実装することを示します。これにより、異なるクラス間での共通の契約を作成し、ポリモーフィズムを実現します。

### 使用法
インターフェースを実装するクラスは、次のように宣言します：

```java
class ClassName implements InterfaceName {
    // インターフェースのメソッドを実装
}
```

複数のインターフェースを実装する場合は、カンマで区切って指定します：

```java
class ClassName implements Interface1, Interface2 {
    // 各インターフェースのメソッドを実装
}
```

### 詳細
- **インターフェースの定義**: インターフェースは、クラスが実装すべきメソッドのシグネチャを定義します。メソッドの本体は持ちません。
- **抽象メソッド**: インターフェース内のメソッドはデフォルトでabstract（抽象）であり、実装クラスで具体的な実装を提供する必要があります。
- **デフォルトメソッド**: Java 8以降、インターフェース内でデフォルトメソッドを定義することが可能になりました。これにより、実装クラスがメソッドをオーバーライドするかどうかを選択できます。

## 例
以下は、インターフェースを実装するクラスの基本的な例です。

```java
// インターフェースの定義
interface Animal {
    void makeSound();
}

// インターフェースを実装するクラス
class Dog implements Animal {
    @Override
    public void makeSound() {
        System.out.println("ワンワン");
    }
}

// 使用例
public class Main {
    public static void main(String[] args) {
        Animal myDog = new Dog();
        myDog.makeSound(); // 出力: ワンワン
    }
}
```

## 説明
- **共通の契約**: 「implements」を使用することで、異なるクラスが同じインターフェースを実装し、同じメソッドを持つことができます。これにより、コードの再利用性と可読性が向上します。
- **多重継承の回避**: Javaはクラスの多重継承をサポートしていませんが、インターフェースを使用することで同様の効果を得ることができます。
- **抽象クラスとの違い**: インターフェースは完全に抽象的ですが、抽象クラスは具象メソッドを持つことができます。インターフェースは複数実装可能ですが、クラスは1つの抽象クラスしか継承できません。

## 一文要約
Javaにおける「implements」は、クラスがインターフェースを実装するためのキーワードであり、ポリモーフィズムとコードの再利用を促進します。
