# استخدام "protected" في لغة البرمجة جافا: دليل شامل

## ملخص
تُستخدم الكلمة المحجوزة "protected" في جافا لتحديد مستوى الوصول إلى الأعضاء (المتغيرات والطرق) في الفئات. وهي تتيح الوصول إلى الأعضاء المحمية من قبل الفئات الفرعية والفئات الأخرى في نفس الحزمة.

## الوثائق
### الغرض
تُستخدم "protected" لتقييد الوصول إلى الأعضاء بحيث يمكن الوصول إليها فقط من الفئات الفرعية (الميراث) أو من الفئات الموجودة في نفس الحزمة. هذا يسمح بتوفير مستوى من الحماية مع إمكانية الوصول الضروري.

### الاستخدام
يمكن استخدام "protected" مع المتغيرات والطرق في الفئات. عند تعريف عضو محمي، يمكن الوصول إليه من قبل:
- الفئات الفرعية، حتى لو كانت في حزم مختلفة.
- الفئات التي تقع في نفس الحزمة.

### التفاصيل
- **الفئات الفرعية**: يمكن للفئات التي ترث من الفئة الأصلية الوصول إلى الأعضاء المحمية.
- **الحزم**: يمكن للفئات الموجودة في نفس الحزمة الوصول إلى الأعضاء المحمية، حتى لو لم تكن ترث.
- **عدم الوصول من خارج الحزمة**: لا يمكن للفئات الموجودة في حزم مختلفة والتي لا ترث من الفئة الأصلية الوصول إلى الأعضاء المحمية.

## الأمثلة
### مثال 1: تعريف عضو محمي
```java
class Parent {
    protected int value;

    protected void displayValue() {
        System.out.println("Value: " + value);
    }
}

class Child extends Parent {
    public void setValue(int value) {
        this.value = value; // يمكن الوصول إلى member المحمي
    }

    public void showValue() {
        displayValue(); // يمكن الوصول إلى method المحمي
    }
}
```

### مثال 2: الوصول من نفس الحزمة
```java
class SamePackage {
    public void accessProtected() {
        Parent parent = new Parent();
        parent.value = 10; // يمكن الوصول إلى member المحمي
        parent.displayValue(); // يمكن الوصول إلى method المحمي
    }
}
```

## الشرح
### المزالق الشائعة
- **عدم القدرة على الوصول من خارج الحزمة**: إذا كنت تحاول الوصول إلى عضو محمي من فئة تقع في حزمة مختلفة وغير مرتبطة بفئة الوالد، فلن تتمكن من الوصول إليه.
- **عدم استخدام "protected" بشكل خاطئ**: من المهم أن نفهم أن "protected" ليست وسيلة لحماية البيانات بشكل كامل، بل هي وسيلة لتسهيل الوصول للبيانات داخل الهيكل الهرمي للفئات.

### ملاحظات إضافية
- من المهم استخدام "protected" بحذر، لأنه قد يؤدي إلى تعقيد التصميم في حالة عدم استخدامه بشكل صحيح.
- يعتبر "protected" خيارًا جيدًا عندما تحتاج إلى إتاحة الوصول لفئات معينة دون جعل الأعضاء عامة.

## ملخص بجملة واحدة
الكلمة المحجوزة "protected" في جافا تُستخدم لتحديد الوصول إلى الأعضاء بحيث يمكن الوصول إليها فقط من الفئات الفرعية والفئات الموجودة في نفس الحزمة.
