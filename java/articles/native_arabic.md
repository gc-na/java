# الكلمة "native" في جافا: مفهومها واستخداماتها

## ملخص
تعتبر الكلمة "native" في جافا واحدة من الكلمات المحجوزة التي تُستخدم للإشارة إلى الدوال (methods) التي تم تنفيذها بلغة برمجة أخرى، مثل C أو C++. تُستخدم هذه الكلمة لتسهيل التفاعل مع الأكواد المكتوبة بلغة أخرى.

## الوثائق
### الغرض
تُستخدم الكلمة "native" لتعريف دوال في جافا تُنفذ في مكتبات خارجية، مما يسمح للمطورين بالاستفادة من وظائف النظام أو المكتبات المكتوبة بلغات أخرى.

### الاستخدام
تتم إضافة الكلمة "native" قبل تعريف الدالة في كود جافا. يجب أن تكون هذه الدالة مرتبطة بمكتبة خارجية عبر Java Native Interface (JNI).

### التفاصيل
- **تعريف دالة Native**: يمكن تعريف دالة باستخدام الكلمة "native" كما يلي:
  ```java
  public native void exampleMethod();
  ```
- **تحميل المكتبة**: يجب استخدام `System.loadLibrary("libraryName");` لتحميل المكتبة التي تحتوي على التنفيذ الفعلي للدالة.
- **التوافق**: يجب أن تكون مكتبة C/C++ متوافقة مع النظام الذي يعمل عليه تطبيق جافا.

## أمثلة
### مثال على دالة Native
```java
public class Example {
    // تعريف دالة Native
    public native int add(int a, int b);
    
    // تحميل المكتبة
    static {
        System.loadLibrary("ExampleLibrary");
    }
    
    public static void main(String[] args) {
        Example example = new Example();
        int result = example.add(5, 10);
        System.out.println("النتيجة: " + result);
    }
}
```

### التنفيذ في C/C++
```c
#include <jni.h>
#include "Example.h"

JNIEXPORT jint JNICALL Java_Example_add(JNIEnv *env, jobject obj, jint a, jint b) {
    return a + b;
}
```

## الشرح
### الأخطاء الشائعة
- **عدم تحميل المكتبة**: إذا لم يتم تحميل المكتبة بشكل صحيح، ستظهر أخطاء في وقت التشغيل.
- **التوافق**: يجب التأكد من أن المكتبة تم إنشاؤها للإصدار الصحيح من Java وبيئة التنفيذ.
- **إدارة الذاكرة**: يجب توخي الحذر عند التعامل مع الذاكرة، حيث أن Java تدير الذاكرة بشكل تلقائي، بينما تحتاج C/C++ إلى إدارة الذاكرة يدويًا.

### ملاحظات إضافية
- استخدام الدوال "native" يمكن أن يضيف تعقيدًا للتطبيق بسبب الحاجة إلى التنسيق بين لغتين مختلفتين.
- تأكد من فهم كيفية عمل JNI قبل استخدام الدوال "native".

## ملخص جملة واحدة
تتيح الكلمة "native" في جافا للمطورين استدعاء دوال مكتوبة بلغة أخرى، مما يسهل دمج الوظائف الخارجية في تطبيقات جافا.
