# الأمر "break" في لغة جافا: الاستخدامات والتفاصيل

## ملخص
الأمر "break" في لغة جافا يُستخدم لإنهاء تنفيذ حلقة (loop) أو عبارة switch بشكل فوري، مما يسمح بالتحكم في تدفق البرنامج بطريقة فعالة.

## التوثيق
### الغرض
يعتبر الأمر "break" أداة التحكم في تدفق البرنامج، حيث يتيح إنهاء الحلقات مثل `for` و `while` و `do-while` أو الخروج من عبارة `switch`. يُستخدم بشكل شائع لتحسين أداء البرنامج وتجنب التكرار غير الضروري.

### الاستخدام
يمكن استخدام الأمر "break" في أي مكان داخل الحلقات أو عبارات switch، ويمكن أن يظهر في أي مكان ضمن الكود، ولكن يجب أن يتم استخدامه بحذر لتجنب الخروج غير المتوقع من الحلقات.

### التفاصيل
- **الحلقات**: عند استخدام "break" داخل حلقة، يتم إنهاء الحلقة على الفور، ويتجاوز البرنامج أي تعليمات متبقية داخل الحلقة.
- **عبارة switch**: يتم استخدام "break" أيضًا لإنهاء تنفيذ الحالات في عبارة switch، حيث يمنع تنفيذ الحالات اللاحقة.

## أمثلة
### مثال على استخدام break في حلقة
```java
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break; // إنهاء الحلقة عندما i تساوي 5
    }
    System.out.println(i);
}
```
**الناتج:**
```
0
1
2
3
4
```

### مثال على استخدام break في عبارة switch
```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("الاثنين");
        break;
    case 2:
        System.out.println("الثلاثاء");
        break;
    case 3:
        System.out.println("الأربعاء");
        break;
    default:
        System.out.println("يوم غير معروف");
}
```
**الناتج:**
```
الأربعاء
```

## الشرح
### الأخطاء الشائعة
- **استخدام break خارج الحلقات**: إذا تم استخدام الأمر "break" خارج الحلقات أو عبارات switch، فسيؤدي ذلك إلى حدوث خطأ في الترجمة.
- **نسيان استخدام break في switch**: إذا تم نسيان استخدام "break" في عبارة switch، سيؤدي ذلك إلى تنفيذ جميع الحالات المتبقية حتى يتم الوصول إلى نهاية switch أو遇到 break.

### ملاحظات إضافية
- يمكن استخدام "break" مع العلامات (labels) للخروج من حلقات متعددة. 
- استخدم الأمر "break" بحذر لتجنب تعقيد تدفق البرنامج.

## ملخص من سطر واحد
الأمر "break" في جافا يُستخدم لإنهاء الحلقات وعبارات switch بشكل فوري، مما يتيح التحكم الفعال في تدفق البرنامج.
