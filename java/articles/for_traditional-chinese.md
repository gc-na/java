# Java 中的 for 迴圈：用法與示例

## 簡介
在 Java 程式設計中，`for` 迴圈是一種控制結構，允許開發者重複執行一段程式碼，直到滿足特定條件為止。這使得 `for` 迴圈成為處理陣列和集合等重複資料的理想選擇。

## 文檔
### 目的
`for` 迴圈的主要目的是提供一種簡潔的方式來執行重複操作，通常用於遍歷數據結構或執行固定次數的重複任務。

### 用法
`for` 迴圈的一般語法如下：

```java
for (initialization; condition; increment) {
    // 執行的程式碼
}
```

- **initialization**：在迴圈開始之前執行的初始化代碼，通常用於定義迴圈變數。
- **condition**：每次迴圈執行前檢查的條件，當條件為 `true` 時，則執行迴圈內的程式碼。
- **increment**：每次迴圈結束時執行的操作，通常用於更新迴圈變數。

### 詳細說明
在 Java 中，`for` 迴圈的設計使其能夠靈活應用於多種場景，包括但不限於：
- 遍歷數組和集合。
- 執行預定次數的運算。
- 控制迴圈的執行流。

## 示例
以下是一些基本的 `for` 迴圈用法示例：

### 示例 1：基本的計數迴圈
```java
for (int i = 0; i < 5; i++) {
    System.out.println("計數：" + i);
}
```
**輸出：**
```
計數：0
計數：1
計數：2
計數：3
計數：4
```

### 示例 2：遍歷數組
```java
int[] numbers = {1, 2, 3, 4, 5};
for (int i = 0; i < numbers.length; i++) {
    System.out.println("數字：" + numbers[i]);
}
```
**輸出：**
```
數字：1
數字：2
數字：3
數字：4
數字：5
```

### 示例 3：使用增量
```java
for (int i = 0; i <= 10; i += 2) {
    System.out.println("偶數：" + i);
}
```
**輸出：**
```
偶數：0
偶數：2
偶數：4
偶數：6
偶數：8
偶數：10
```

## 解釋
在使用 `for` 迴圈時，開發者可能會遇到以下常見的陷阱：
- **條件設置錯誤**：如果條件設置不當，可能導致無限迴圈或迴圈不執行。
- **增量錯誤**：未正確更新迴圈變數，將影響迴圈的運行。
- **索引越界**：在遍歷數組或集合時，必須確保不超過其邊界，否則將引發 `ArrayIndexOutOfBoundsException`。

## 總結
Java 中的 `for` 迴圈是一種強大而靈活的控制結構，適用於各種重複操作，適合用於數據遍歷和計數任務。
