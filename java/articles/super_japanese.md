# Javaにおける「super」キーワードの解説

## 概要
Javaプログラミング言語における「super」キーワードは、親クラスのメンバー（フィールドやメソッド）にアクセスするために使用されます。このキーワードは、サブクラスが親クラスの機能を拡張する際に特に重要です。

## ドキュメンテーション
「super」キーワードは、以下の目的で使用されます。

1. **親クラスのコンストラクタを呼び出す**: サブクラスのコンストラクタ内で親クラスのコンストラクタを呼び出すために使用されます。
2. **親クラスのメソッドを呼び出す**: サブクラスでオーバーライドされたメソッドの親クラスの実装にアクセスすることができます。
3. **親クラスのフィールドにアクセスする**: サブクラスで同名のフィールドが存在する場合、親クラスのフィールドを参照することができます。

### 使用法
- 親クラスのコンストラクタを呼び出す場合：
  ```java
  super(); // デフォルトコンストラクタを呼び出す
  super(引数); // 引数付きのコンストラクタを呼び出す
  ```

- 親クラスのメソッドを呼び出す場合：
  ```java
  super.methodName(); // 親クラスのmethodNameメソッドを呼び出す
  ```

- 親クラスのフィールドにアクセスする場合：
  ```java
  this.fieldName; // サブクラスのフィールド
  super.fieldName; // 親クラスのフィールド
  ```

## 例
以下は、「super」を使用した基本的な例です。

```java
class Parent {
    String name = "親クラス";

    Parent() {
        System.out.println("親クラスのコンストラクタ");
    }

    void display() {
        System.out.println("親クラスのメソッド");
    }
}

class Child extends Parent {
    String name = "子クラス";

    Child() {
        super(); // 親クラスのコンストラクタを呼び出す
        System.out.println("子クラスのコンストラクタ");
    }

    void display() {
        super.display(); // 親クラスのメソッドを呼び出す
        System.out.println("子クラスのメソッド");
    }

    void showNames() {
        System.out.println("親の名前: " + super.name); // 親クラスのフィールドにアクセス
        System.out.println("子の名前: " + this.name); // 子クラスのフィールドにアクセス
    }
}

public class Main {
    public static void main(String[] args) {
        Child child = new Child();
        child.display();
        child.showNames();
    }
}
```

## 説明
「super」キーワードの一般的な落とし穴や注意点には以下があります。

- **名前の衝突**: サブクラスが親クラスと同名のフィールドやメソッドを持つ場合、明示的に「super」を使用しないと親クラスのメンバーにアクセスできないため、注意が必要です。
- **コンストラクタの呼び出し順序**: 親クラスのコンストラクタはサブクラスのコンストラクタよりも先に呼び出されます。これにより、親クラスのフィールドが正しく初期化されてからサブクラスのコンストラクタが実行されます。

## 一文要約
Javaにおける「super」キーワードは、サブクラスが親クラスのメンバーにアクセスするための重要な手段です。
