# Java 中的 while 循環：功能、用法與範例

## 概要
在 Java 程式設計中，`while` 循環是一種控制結構，用於重複執行一段程式碼，直到指定的條件不再滿足為止。

## 文檔
`while` 循環的基本語法如下：

```java
while (condition) {
    // 要執行的程式碼
}
```

### 目的
`while` 循環用於在條件為真（true）時重複執行一段程式碼，這使得它非常適合於需要不斷檢查某個條件的情況。

### 用法
1. **初始化條件**：在進入 `while` 循環之前，必須確保條件已經正確初始化。
2. **執行循環**：當條件為真時，循環內部的程式碼將被執行。
3. **更新條件**：在循環內部，應該在適當的時候更新條件，以避免無限循環。

## 範例
以下是使用 `while` 循環的簡單範例：

### 範例 1：從 1 數到 5

```java
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
```

### 範例 2：計算總和

```java
int sum = 0;
int number = 1;
while (number <= 10) {
    sum += number;
    number++;
}
System.out.println("總和是：" + sum);
```

## 解釋
在使用 `while` 循環時，開發者應注意以下幾點：

- **無限循環**：如果條件始終為真，將導致無限循環，這會使程式無法正常結束。
- **邊界條件**：確保條件的邊界清晰明確，以避免意外的行為。
- **程式碼可讀性**：保持循環內部程式碼的簡潔性，以提高可讀性。

## 一句總結
`while` 循環是 Java 中一個強大的控制結構，用於在條件為真時重複執行程式碼。
