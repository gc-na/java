# Java 中的 "if" 條件語句：用於控制程序流程的基本工具

## 概述
在 Java 程式設計中，`if` 條件語句是用來執行條件判斷的基礎結構。它允許開發者根據特定條件的真偽來執行不同的程式碼區塊，從而實現更靈活和動態的程序控制。

## 文檔
`if` 語句的主要用途是根據某個布林表達式的結果來決定程式的執行路徑。當表達式返回 `true` 時，緊隨其後的程式碼將被執行；若為 `false`，則該程式碼將被跳過。Java 中的 `if` 語句也可以與 `else` 和 `else if` 結合使用，以處理多個條件。

**基本語法：**
```java
if (條件) {
    // 當條件為 true 時執行的程式碼
} else {
    // 當條件為 false 時執行的程式碼
}
```

**使用示例：**
```java
int number = 10;

if (number > 0) {
    System.out.println("數字是正數");
} else {
    System.out.println("數字不是正數");
}
```

## 範例
### 基本用法
以下是幾個簡單的 `if` 語句範例：

1. **單一條件判斷：**
```java
int age = 18;
if (age >= 18) {
    System.out.println("你是成年人");
}
```

2. **使用 `else`：**
```java
int score = 75;
if (score >= 60) {
    System.out.println("通過考試");
} else {
    System.out.println("未通過考試");
}
```

3. **多個條件判斷：**
```java
int temperature = 30;

if (temperature > 30) {
    System.out.println("天氣炎熱");
} else if (temperature >= 20) {
    System.out.println("天氣舒適");
} else {
    System.out.println("天氣寒冷");
}
```

## 解釋
在使用 `if` 語句時，有幾個常見的陷阱需要注意：

- **條件的類型**：確保條件是布林類型，或能被自動轉換為布林值。使用不當會導致編譯錯誤。
  
- **大括號使用**：雖然對於單行程式碼可以省略大括號，但為了可讀性和易於擴展，建議始終使用大括號。

- **嵌套判斷**：過多的嵌套 `if` 語句會使程式碼變得難以維護。考慮使用其他結構，如 `switch` 或函數來簡化邏輯。

- **邏輯運算符**：可以在 `if` 條件中使用邏輯運算符（如 `&&` 和 `||`）來組合多個條件，但要注意括號的使用以避免優先級錯誤。

## 一句總結
`if` 語句是 Java 中用於執行條件判斷的基本工具，能夠根據條件的真偽控制程式的執行流程。
