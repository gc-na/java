# Java 整數型別 int：全面指南

## 概要
`int` 是 Java 語言中用於表示整數的基本數據類型之一，它占用 4 個字節（32 位元），並且可以儲存範圍從 -2,147,483,648 到 2,147,483,647 的整數。

## 文檔
在 Java 中，`int` 是基本數據類型之一，用於存儲整數值。Java 的數據類型分為兩大類：原始數據類型（如 `int`、`float`、`char` 等）與參考數據類型（如 `String`、`Array` 等）。`int` 型別在記憶體中以二進位形式儲存，並且在執行過程中效率高。

### 用法
在 Java 中，您可以簡單地使用 `int` 來宣告變數，並為其分配整數值。以下是 `int` 的基本語法：

```java
int variableName = value;
```

### 詳細說明
- **範圍**：`int` 的取值範圍是 -2,147,483,648 到 2,147,483,647。
- **預設值**：當宣告一個 `int` 變數但未初始化時，其預設值為 0。
- **運算**：`int` 支援各種數學運算（如加法、減法、乘法和除法），並且這些運算的結果也將是 `int` 型別（除非涉及浮點數運算）。
  
```java
int a = 5;
int b = 10;
int sum = a + b; // sum的值為15
```

## 範例
以下是幾個簡單的使用範例：

### 宣告和初始化
```java
int number = 42;
```

### 基本運算
```java
int x = 10;
int y = 20;
int result = x * y; // result 的值為200
```

### 流程控制
```java
for (int i = 0; i < 5; i++) {
    System.out.println("數字：" + i);
}
```

## 解釋
在使用 `int` 時，有一些常見的陷阱和注意事項：

- **溢位**：當計算結果超過 `int` 的範圍時，會發生溢位，導致結果不正確。例如，`int overflow = 2147483647 + 1;` 將會得到負數。
- **整數除法**：當兩個 `int` 相除時，結果會自動進行取整操作。例如，`5 / 2` 的結果是 `2` 而不是 `2.5`。
- **類型轉換**：在某些情況下，您可能需要將 `int` 轉換為其他數據類型，例如 `double` 或 `float`，以避免精度損失。

## 一句總結
`int` 是 Java 中的基本整數型別，用於高效地儲存和處理整數值。
