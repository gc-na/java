# Javaの「if」文: 条件分岐の基本

## 概要
Javaの「if」文は、プログラムの実行フローを制御するための基本的な条件分岐構文です。この命令を使用することで、特定の条件が真である場合にのみ特定のコードブロックを実行することが可能になります。

## ドキュメンテーション
### 目的
「if」文は、条件に基づいて異なる処理を実行するために使用されます。これにより、プログラムは動的に応答し、異なる状況に対応できます。

### 使用法
Javaの「if」文は以下のように記述します。

```java
if (条件) {
    // 条件が真の場合に実行されるコード
}
```

### 詳細
- **条件**: ブール式（true または false を返す式）でなければなりません。
- **ブロック**: 条件が真の場合に実行するコードブロックは波括弧 `{}` で囲います。ブロックが1行のみの場合は波括弧を省略することができます。

### 拡張
「if」文は「else」や「else if」を使って、複数の条件を簡潔に表現することができます。

```java
if (条件1) {
    // 条件1が真の場合
} else if (条件2) {
    // 条件2が真の場合
} else {
    // 条件1と条件2がどちらも偽の場合
}
```

## 例
### 基本的な使用例
```java
int number = 10;

if (number > 5) {
    System.out.println("numberは5より大きい");
}
```

### 複数の条件を持つ例
```java
int score = 85;

if (score >= 90) {
    System.out.println("優");
} else if (score >= 75) {
    System.out.println("良");
} else {
    System.out.println("可");
}
```

## 説明
### 一般的な落とし穴
- **条件式の間違い**: 条件が正しく評価されない場合、意図した通りにコードが実行されません。条件式を慎重に確認してください。
- **波括弧の省略**: ブロックが1行のみの場合に波括弧を省略することができますが、後でコードを追加する際に意図しない動作を引き起こす可能性があるため、常に波括弧を使うことを推奨します。

### 注意点
- ネストされた「if」文を使用することができますが、可読性が低下する可能性があるため、適切なインデントを維持し、必要に応じてコメントを追加することが重要です。

## 一言まとめ
Javaの「if」文は、条件に基づいてプログラムの実行フローを制御するための重要な構文です。
