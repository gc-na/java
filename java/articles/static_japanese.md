# Javaにおける「static」の使い方と特徴

## 概要
Javaの「static」キーワードは、クラスに属するメンバー（フィールドやメソッド）を定義するために使用されます。これにより、インスタンス化せずにアクセスできる特性を持ちます。

## ドキュメンテーション
### 目的
`static`は、クラスのメンバーが特定のクラスに固有であり、インスタンスに依存しないことを示します。これにより、メモリの効率を向上させ、クラスに関連する共通の機能を提供します。

### 使用法
`static`キーワードは、フィールド、メソッド、ブロックに適用できます。以下のように使われます：

- **フィールドの定義**: クラスに一つの静的変数（クラス変数）を持たせることができます。
- **メソッドの定義**: クラスに静的メソッドを定義することで、インスタンス化せずに呼び出すことができます。
- **静的ブロック**: クラスロード時に一度だけ実行される初期化コードを定義するために使用されます。

### 詳細
- **静的フィールド**: クラスのすべてのインスタンスで共有される変数です。静的フィールドは、`className.fieldName`の形式でアクセスされます。
- **静的メソッド**: インスタンスに依存しないメソッドであり、データにアクセスするためには他の静的フィールドまたはメソッドのみを使用できます。`className.methodName()`で呼び出します。
- **静的ブロック**: クラスがロードされるときに実行されるコードで、初期化処理を行うのに便利です。

## 例
以下に`static`キーワードの基本的な使用例を示します。

```java
public class Sample {
    // 静的フィールド
    static int count = 0;

    // 静的メソッド
    static void increment() {
        count++;
    }

    // 静的ブロック
    static {
        count = 10; // クラスがロードされたときに実行される
    }
}

public class Main {
    public static void main(String[] args) {
        // 静的メソッドを呼び出し
        Sample.increment();
        System.out.println(Sample.count); // 出力: 11
    }
}
```

## 解説
- **インスタンスに依存しない**: `static`メンバーはインスタンス化せずにアクセスできるため、メモリ効率が良くなります。
- **アクセス制御**: `static`メンバーは、クラス名を通じてアクセスするため、他のインスタンスの状態に依存しません。
- **注意点**: 静的メソッドからは、非静的メンバーに直接アクセスできないため、エラーが発生する可能性があります。静的フィールドの値が複数のスレッドから変更される場合、スレッドセーフでない環境では競合状態が発生することがあります。

## 一文要約
Javaの`static`キーワードは、クラスに固有のメンバーを定義し、インスタンス化せずにアクセスできる特性を提供します。
