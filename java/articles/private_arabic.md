# الخاص في لغة جافا: التحكم في الوصول إلى الأعضاء

## ملخص
الكلمة المحجوزة "private" في لغة جافا تستخدم لتحديد مستوى الوصول للأعضاء (الحقول والطرق) في الفصول. يُعتبر استخدام "private" أسلوباً فعالاً لتحقيق التجريد وإخفاء البيانات، مما يساهم في كتابة كود أكثر أماناً ونظافة.

## الوثائق
تُستخدم "private" لتقييد إمكانية الوصول إلى الأعضاء داخل فصل معين. عندما يتم تعريف حقل أو طريقة على أنها "private"، لا يمكن الوصول إليها من خارج هذا الفصل، مما يمنع التلاعب غير المرغوب فيه. هذا يساهم في حماية البيانات وضمان أن يتم الوصول إليها فقط من خلال واجهات محددة، مثل الطرق العامة.

### الاستخدام
لإعلان حقل أو طريقة على أنها "private"، يتم وضع الكلمة المحجوزة "private" قبل تعريف الحقل أو الطريقة:

```java
public class MyClass {
    private int myPrivateVariable;

    private void myPrivateMethod() {
        // تنفيذ بعض التعليمات البرمجية
    }
}
```

## الأمثلة
فيما يلي بعض الأمثلة الأساسية لاستخدام الكلمة المحجوزة "private":

### مثال 1: حقل خاص
```java
public class Person {
    private String name;

    public Person(String name) {
        this.name = name;
    }

    public String getName() {
        return name; // الوصول إلى الحقل الخاص من داخل الفصل
    }
}
```

### مثال 2: طريقة خاصة
```java
public class Calculator {
    private int add(int a, int b) {
        return a + b; // طريقة خاصة لا يمكن الوصول إليها من الخارج
    }

    public int addPublic(int a, int b) {
        return add(a, b); // استخدام الطريقة الخاصة من داخل طريقة عامة
    }
}
```

## الشرح
من الشائع أن يخطئ المبتدئون في فهم مفهوم "private". يجب أن يتذكر المطورون أن العضو الخاص لا يمكن الوصول إليه من فصول أخرى، مما يعني أنه لا يمكن استخدامه مباشرة من كود خارج الفصل. إذا حاولت الوصول إلى حقل أو طريقة خاصة، ستظهر لك رسالة خطأ في وقت الترجمة.

### ملاحظات إضافية
- استخدام "private" يساهم في حماية البيانات ويقلل من الأخطاء الناتجة عن الوصول غير المرغوب فيه.
- إذا كنت بحاجة للوصول إلى الحقول الخاصة من فصول أخرى، يمكنك استخدام الطرق العامة مثل get وset.
- من المهم ملاحظة أن "private" لا تمنع الوصول إلى الحقول من الفصول الفرعية (subclasses)، حيث يمكن للفصول الفرعية الوصول إلى الأعضاء الخاصة عن طريق الطرق العامة.

## ملخص بسيط
تُستخدم الكلمة المحجوزة "private" في جافا لتقييد الوصول إلى الأعضاء داخل الفصل، مما يعزز الأمان والتنظيم في الكود.
