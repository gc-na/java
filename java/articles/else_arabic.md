# استخدام جملة else في لغة Java

## ملخص
تُستخدم جملة "else" في لغة Java لتحديد كتلة من التعليمات البرمجية التي تُنفذ إذا كان الشرط المحدد في جملة "if" غير صحيح. تعتبر "else" جزءاً أساسياً من التحكم في التدفق في البرمجة.

## الوثائق
تعتبر جملة "else" جزءًا من الجمل الشرطية في Java، والتي تتيح للمطورين اتخاذ قرارات بناءً على شروط معينة. يتم استخدامها بعد جملة "if" لتوفير بديل يتم تنفيذه عندما لا يتم استيفاء الشرط في جملة "if".

### الاستخدام
تأتي جملة "else" بعد جملة "if" ويمكن استخدامها مع جملة "if" واحدة أو مع جملة "if" متعددة عبر "else if". التركيب الأساسي لجملة "else" هو كما يلي:

```java
if (condition) {
    // كتلة الكود للتنفيذ إذا كان الشرط صحيحًا
} else {
    // كتلة الكود للتنفيذ إذا كان الشرط غير صحيح
}
```

يمكن استخدام "else" مع جملة "if" على النحو التالي:

```java
if (x > 10) {
    System.out.println("x أكبر من 10");
} else {
    System.out.println("x ليس أكبر من 10");
}
```

## الأمثلة
### مثال بسيط
```java
int number = 5;

if (number > 0) {
    System.out.println("العدد موجب");
} else {
    System.out.println("العدد ليس موجب");
}
```

### مثال مع else if
```java
int score = 75;

if (score >= 90) {
    System.out.println("ممتاز");
} else if (score >= 75) {
    System.out.println("جيد جداً");
} else {
    System.out.println("مقبول");
}
```

## الشرح
رغم أن جملة "else" تبدو بسيطة، إلا أن هناك بعض الأخطاء الشائعة التي قد تحدث عند استخدامها:
- **عدم وجود جملة if**: لا يمكن استخدام "else" بمفردها، يجب أن تسبقها جملة "if".
- **عدم استخدام الأقواس**: عند وجود أكثر من تعليمة في كتلة "else"، يجب استخدام الأقواس لتجنب الأخطاء.
- **تداخل الجمل الشرطية**: يمكن أن يؤدي الاستخدام غير الصحيح للجمل الشرطية المتداخلة إلى تعقيد الشيفرة وزيادة احتمال الأخطاء.

### ملاحظات إضافية
- يمكن استخدام "else" مع "switch" أيضًا، ولكن ليس بشكل مباشر. يجب أن يكون لديك "case" محدد للاستخدام مع "default" بدلاً من "else".

## ملخص جملة واحدة
جملة "else" في Java تُستخدم لتحديد الكود الذي سيتم تنفيذه عندما لا يكون الشرط في جملة "if" صحيحًا.
