# Javaにおける「else」文の使い方と詳細ガイド

## 概要
Javaにおける「else」文は、条件分岐を制御するための基本的な構文の一つです。if文と組み合わせて使用することで、特定の条件が成立しない場合の処理を定義できます。

## ドキュメンテーション
「else」文は、条件が真でない場合に実行されるコードブロックを指定するために使用されます。通常、「if」文と共に使われ、条件が満たされない場合の代替の処理を提供します。

### 使用方法
基本的な構文は次の通りです。

```java
if (条件) {
    // 条件が真の場合に実行されるコード
} else {
    // 条件が偽の場合に実行されるコード
}
```

### 詳細
- **条件式**: if文の条件部分に記述します。真または偽を返す式でなければなりません。
- **コードブロック**: 条件が真または偽の場合に実行されるコードのセットを中括弧 `{}` で囲みます。コードブロックは、必要に応じて単一の文であっても構いません。

## 例
以下に「else」文の基本的な使用例を示します。

```java
public class ElseExample {
    public static void main(String[] args) {
        int number = 10;

        if (number > 0) {
            System.out.println("数は正です。");
        } else {
            System.out.println("数は非正です。");
        }
    }
}
```

このプログラムでは、変数 `number` が0より大きい場合、「数は正です。」と出力され、それ以外の場合は「数は非正です。」と出力されます。

## 説明
「else」文を使用する際の一般的な落とし穴や注意点は以下の通りです。

- **条件式の誤り**: 条件式が間違っていると、意図した動作をしません。特に、`==` と `=` の使い分けには注意が必要です。
- **複数の条件**: 複数の条件を評価したい場合は、`else if` を使用することを検討してください。これにより、より複雑な条件分岐を作成できます。

例:
```java
if (number > 0) {
    System.out.println("数は正です。");
} else if (number < 0) {
    System.out.println("数は負です。");
} else {
    System.out.println("数はゼロです。");
}
```
