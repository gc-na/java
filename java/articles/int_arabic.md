# int في لغة JAVA: كل ما تحتاج لمعرفته

## ملخص
النوع الأساسي "int" في لغة JAVA يُستخدم لتمثيل الأعداد الصحيحة. إنه أحد الأنواع الأكثر استخدامًا في البرمجة، حيث يوفر أداءً عاليًا وسهولة في التعامل مع القيم العددية.

## الوثائق
### الغرض
يُستخدم "int" لتخزين القيم العددية الصحيحة في JAVA. يتراوح نطاقه من -2,147,483,648 إلى 2,147,483,647، مما يجعله مناسبًا للعديد من التطبيقات التي تتطلب التعامل مع الأعداد الصحيحة.

### الاستخدام
يمكن تعريف متغير من نوع "int" عن طريق كتابة الكلمة المفتاحية "int" متبوعة باسم المتغير. على سبيل المثال:

```java
int myNumber;
```

يمكنك أيضًا تعيين قيمة أولية للمتغير عند تعريفه:

```java
int myNumber = 10;
```

### التفاصيل
- **الحجم**: يشغل "int" 4 بايت (32 بت) في الذاكرة.
- **العمليات**: يمكن إجراء العمليات الحسابية مثل الجمع (+)، الطرح (-)، الضرب (*)، والقسمة (/) على متغيرات "int".
- **المقارنة**: يمكن مقارنة القيم باستخدام معاملات المقارنة مثل `==`, `!=`, `<`, `>`, `<=`, `>=`.

## الأمثلة
### مثال 1: تعريف متغير int
```java
int age = 25;
System.out.println("العمر هو: " + age);
```

### مثال 2: إجراء عمليات حسابية
```java
int a = 10;
int b = 20;
int sum = a + b;
System.out.println("مجموع a و b هو: " + sum);
```

### مثال 3: استخدام int في الحلقات
```java
for (int i = 0; i < 5; i++) {
    System.out.println("رقم: " + i);
}
```

## الشرح
### الأخطاء الشائعة
- **تجاوز النطاق**: إذا حاولت تخزين قيمة أكبر من 2,147,483,647 أو أقل من -2,147,483,648، سيحدث تجاوز في النطاق مما يؤدي إلى نتائج غير متوقعة.
- **اختلاط الأنواع**: يجب الانتباه عند إجراء العمليات على أنواع مختلفة مثل "int" و"double"، حيث قد يحدث فقدان الدقة.

### ملاحظات إضافية
- "int" هو نوع بيانات أساسي، مما يعني أنه يتم تخزين القيم مباشرة في الذاكرة، مما يوفر أداءً أفضل مقارنة بالأنواع المرجعية.
- في حالة الحاجة إلى تخزين أعداد صحيحة أكبر من النطاق المذكور، يمكنك استخدام "long" الذي يوفر نطاقًا أكبر.

## ملخص بجملة واحدة
"int" في JAVA هو نوع بيانات أساسي يستخدم لتخزين الأعداد الصحيحة، ويتميز بأداء عالي ونطاق واسع من القيم.
