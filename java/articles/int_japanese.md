# Javaにおける「int」データ型の使い方と特徴

## 概要
Javaにおける「int」は、整数を表す基本データ型です。32ビットの符号付き整数を格納でき、数値計算やループ制御など、さまざまな場面で広く使用されます。

## ドキュメンテーション
### 目的
「int」データ型は、整数値を扱うための基本的な手段を提供します。Javaでは、整数の演算や比較を行う際に最も一般的に使用されるデータ型の一つです。

### 使用法
「int」は、次のように宣言および使用します。

```java
int myNumber = 10; // 整数の初期化
```

#### 詳細
- **サイズ**: 「int」は常に32ビット（4バイト）で、値の範囲は-2,147,483,648から2,147,483,647までです。
- **デフォルト値**: int型の変数を初期化しない場合、そのデフォルト値は0です。
- **演算**: 加算、減算、乗算、除算などの基本的な算術演算をサポートしています。整数同士の演算結果も整数です。

### 注意事項
- **オーバーフロー**: intの最大値を超えると、オーバーフローが発生し、負の数に戻ります（例: 2,147,483,647 + 1 = -2,147,483,648）。
- **型変換**: 他のデータ型との演算では、明示的な型キャストが必要な場合があります。特に、intとfloatの間では注意が必要です。

## 例
基本的な「int」の使用例を以下に示します。

```java
public class IntExample {
    public static void main(String[] args) {
        int a = 5;
        int b = 10;
        int sum = a + b; // 加算
        int product = a * b; // 乗算
        
        System.out.println("合計: " + sum); // 出力: 合計: 15
        System.out.println("積: " + product); // 出力: 積: 50
    }
}
```

## 説明
「int」を使用する際の一般的な落とし穴として、オーバーフローや型変換の問題があります。特に、計算結果が「int」の範囲を超える場合に注意が必要です。また、整数を浮動小数点数と混同しないようにすることも重要です。整数演算の結果は常に整数であるため、意図しない結果を避けるためには、必要に応じて型変換を行うことが大切です。

## 一文要約
Javaにおける「int」は、32ビットの符号付き整数を表す基本データ型で、様々な数値演算に広く利用されます。
