# Java 中的 "do" 迴圈 - 用法與範例

## 摘要
在 Java 程式語言中，"do" 迴圈是一種控制結構，用於重複執行一段程式碼，直到滿足特定的條件。它與 "while" 迴圈類似，但在執行條件判斷之前至少執行一次迴圈體，這使得 "do" 迴圈在某些情況下特別有用。

## 文件說明
### 目的
"do" 迴圈的主要目的是讓開發者能夠重複執行一段程式碼，直到使用者或程式滿足某個條件為止。這種迴圈結構確保了迴圈內的程式碼至少會被執行一次。

### 用法
"do" 迴圈的基本語法如下：

```java
do {
    // 執行的程式碼
} while (條件);
```

在這個語法中：
- `do` 關鍵字後面緊跟著要執行的程式碼塊。
- 在程式碼塊執行完後，會進行條件判斷。如果條件為 `true`，則迴圈會再次執行；如果為 `false`，則迴圈結束。

### 詳細說明
- **優先執行**：與 `while` 迴圈不同的是，"do" 迴圈會先執行程式碼，再進行條件判斷，這是其主要特點。
- **使用場景**：當需要至少執行一次程式碼，例如獲取用戶輸入並進行驗證時，"do" 迴圈是非常合適的選擇。
- **條件**：條件部分是布林表達式，當其為 `true` 時，迴圈持續執行。可以使用任何有效的布林表達式。

## 範例
以下是一個使用 "do" 迴圈的基本範例，該範例將不斷提示用戶輸入數字，直到用戶輸入負數為止：

```java
import java.util.Scanner;

public class DoWhileExample {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int number;

        do {
            System.out.print("請輸入一個數字（負數將結束）：");
            number = scanner.nextInt();
            System.out.println("您輸入的數字是：" + number);
        } while (number >= 0);

        System.out.println("程式結束。");
        scanner.close();
    }
}
```

## 解釋
### 常見問題
- **條件永遠為真**：如果條件設置不當，可能導致無窮迴圈，需謹慎設計條件判斷。
- **使用者輸入**：在處理使用者輸入時，應考慮到輸入的有效性，以避免程式異常。
- **性能考量**：雖然 "do" 迴圈方便，但在某些情況下可能不如其他迴圈結構（如 "for" 或 "while"）高效，需根據實際需求選擇合適的迴圈。

## 一句總結
"do" 迴圈在 Java 中是一種能夠保證程式碼至少執行一次的控制結構，適用於需要重複執行的場景。
