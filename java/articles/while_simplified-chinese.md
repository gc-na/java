# Java中的"while"循环：用法与示例

## 摘要
"while"循环是Java中的一种控制结构，用于重复执行一段代码，直到指定的条件为假。它在处理需要反复执行的任务时非常有用，尤其是在循环次数不确定的情况下。

## 文档
### 目的
"while"循环的主要目的是在条件为真的情况下重复执行一段代码块。这使得程序能够根据运行时条件动态地执行任务。

### 用法
"while"循环的基本语法如下：

```java
while (条件) {
    // 循环体
}
```

- **条件**：一个布尔表达式。只要条件为真，循环体中的代码就会被执行。
- **循环体**：在条件为真时执行的代码块。

### 详细信息
- 在"while"循环中，如果条件在第一次检查时为假，循环体将不会被执行。
- 确保在循环体内部有更改条件的代码，否则循环将变成无限循环，导致程序挂起。
- "while"循环可以与其他控制结构（如if语句）结合使用，以实现复杂的逻辑。

## 示例
### 基本示例
以下是一个简单的示例，演示如何使用"while"循环打印从1到5的数字：

```java
public class WhileExample {
    public static void main(String[] args) {
        int i = 1;
        while (i <= 5) {
            System.out.println(i);
            i++;
        }
    }
}
```

### 无限循环示例
如果条件没有在循环体内得到更改，就会导致无限循环：

```java
public class InfiniteWhileExample {
    public static void main(String[] args) {
        int i = 1;
        while (i <= 5) {
            System.out.println(i);
            // i++ 被注释掉了，导致无限循环
        }
    }
}
```

## 说明
- **常见问题**：在使用"while"循环时，确保条件能够在某个时刻变为假，以避免无限循环。
- **注意事项**：使用"break"语句可以在特定条件下提前退出循环，"continue"语句可以跳过当前循环的迭代，继续下一次的检查。
- **性能问题**：在某些情况下，过多的循环可能会导致性能问题，因此在设计时要谨慎考虑循环的使用。

## 一句话总结
"while"循环是Java中用于在条件为真时重复执行代码块的控制结构。
