# جملة "case" في لغة JAVA: فهم دقيق واستخدام فعال

## ملخص
تعتبر جملة "case" في لغة JAVA جزءًا من التركيب الشرطي "switch"، وتستخدم لتحديد مسارات التنفيذ بناءً على قيمة معينة. توفر هذه الجملة وسيلة فعالة لتنظيم الشيفرة وتقليل التعقيد.

## التوثيق
تستخدم جملة "case" في JAVA ضمن جملة "switch" لتحديد الكتل البرمجية التي يجب تنفيذها بناءً على القيمة المدخلة. تكون بنية الجملة كالتالي:

```java
switch (expression) {
    case value1:
        // كود للتنفيذ إذا كانت القيمة تساوي value1
        break;
    case value2:
        // كود للتنفيذ إذا كانت القيمة تساوي value2
        break;
    default:
        // كود للتنفيذ إذا لم تتطابق أي من القيم السابقة
}
```

### الغرض
تساعد جملة "case" المبرمجين في كتابة شيفرة أكثر وضوحًا وإدارةً للأخطاء من خلال تقليل عدد الجمل الشرطية المتداخلة.

### الاستخدام
تستخدم جملة "case" مع تعبير "switch" لتحديد القيم التي يمكن أن تأخذها المتغيرات. يمكن أن تكون القيم من نوع البيانات الأساسية مثل `int`، `char`، أو `String` (ابتداءً من JAVA 7).

## أمثلة
### مثال 1: استخدام "case" مع الأعداد الصحيحة
```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("الإثنين");
        break;
    case 2:
        System.out.println("الثلاثاء");
        break;
    case 3:
        System.out.println("الأربعاء");
        break;
    default:
        System.out.println("يوم غير معروف");
}
```

### مثال 2: استخدام "case" مع النصوص
```java
String fruit = "تفاح";
switch (fruit) {
    case "موز":
        System.out.println("الفاكهة هي موز");
        break;
    case "تفاح":
        System.out.println("الفاكهة هي تفاح");
        break;
    case "برتقال":
        System.out.println("الفاكهة هي برتقال");
        break;
    default:
        System.out.println("فاكهة غير معروفة");
}
```

## الشرح
### العثرات الشائعة
- **نسيان جملة "break"**: إذا نسيت إضافة جملة `break` بعد تنفيذ الكود، سيستمر التنفيذ في الحالات التالية، مما قد يؤدي إلى نتائج غير متوقعة.
- **استخدام قيم غير متوافقة**: تأكد من توافق نوع القيم المستخدمة في جملة "case" مع نوع التعبير في جملة "switch". على سبيل المثال، لا يمكنك استخدام `String` مع `int`.
- **تكرار القيم**: لا يمكن أن تحتوي جمل "case" على قيم مكررة، وإلا سيظهر خطأ في وقت الترجمة.

## ملخص بسيط
تساعد جملة "case" في JAVA على تنظيم الشيفرة بشكل أفضل من خلال توفير مسارات تنفيذ مرنة بناءً على قيم معينة.
