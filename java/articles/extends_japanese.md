# Javaにおける「extends」キーワードの完全ガイド

## 概要
Javaの「extends」キーワードは、クラスが別のクラスを継承する際に使用されます。これにより、親クラスのプロパティやメソッドを子クラスが引き継ぐことができ、コードの再利用性や拡張性が向上します。

## ドキュメンテーション
### 目的
「extends」は、クラス間の継承関係を定義するためのキーワードです。特に、サブクラスはスーパークラスの特性を引き継ぎ、追加またはオーバーライドすることができます。

### 使用法
Javaでクラスを継承する際は、以下の構文を使用します。

```java
class 子クラス名 extends 親クラス名 {
    // 子クラスのフィールドやメソッド
}
```

この構文により、子クラスは親クラスのフィールドやメソッドにアクセスできるようになります。Javaでは、一度に1つのクラスのみを継承することができるため（単一継承）、クラスの設計がシンプルになります。

### 詳細
- **親クラスと子クラス**: 親クラスは一般的な特性を持ち、子クラスはその特性を拡張または特化させます。
- **オーバーライド**: 子クラスは親クラスのメソッドをオーバーライドすることができ、独自の実装を提供できます。
- **superキーワード**: 子クラスは`super`を使用して親クラスのコンストラクタやメソッドを呼び出すことができます。
- **アクセス制御**: 親クラスのメンバーが`protected`または`public`であれば、子クラスからアクセス可能ですが、`private`メンバーにはアクセスできません。

## 例
以下は、「extends」を使用した基本的なクラス継承の例です。

```java
class 動物 {
    void 鳴く() {
        System.out.println("動物が鳴いています");
    }
}

class 犬 extends 動物 {
    void 鳴く() {
        System.out.println("ワンワン");
    }
}

public class メイン {
    public static void main(String[] args) {
        犬 myDog = new 犬();
        myDog.鳴く(); // 出力: ワンワン
    }
}
```

この例では、`犬`クラスが`動物`クラスを継承しており、`鳴く`メソッドをオーバーライドしています。

## 説明
### よくある落とし穴
- **多重継承の制限**: Javaは多重継承をサポートしていないため、1つのクラスからのみ継承できます。これにより、複雑な継承階層を避けることができます。
- **オーバーライドの注意点**: 親クラスのメソッドをオーバーライドする際は、親クラスのメソッドが`final`または`static`として宣言されている場合、オーバーライドできません。
- **コンストラクタの呼び出し**: 子クラスのコンストラクタ内で`super()`を明示的に呼び出さない場合、親クラスのデフォルトコンストラクタが自動的に呼び出されます。

## 一行要約
Javaの「extends」キーワードは、クラス継承を通じてコードの再利用性を高め、親クラスの特性を子クラスに引き継ぐために使用されます。
