# Java 中的 for 循環語句

## 概述
`for` 循環是 Java 程式語言中一個基本的控制結構，用來重複執行一段代碼，直到滿足特定條件。它提供了一種簡潔且高效的方法來遍歷數組或集合。

## 文檔
### 目的
`for` 循環的主要目的是在滿足特定條件時重複執行某段代碼，特別是在已知迭代次數的情況下。這使得程式邏輯清晰且易於維護。

### 使用方法
`for` 循環的基本語法如下：
```java
for (初始化; 條件; 更新) {
    // 要執行的代碼
}
```
- **初始化**：在循環開始前執行一次，通常用來定義和初始化迴圈變量。
- **條件**：在每次迴圈執行前進行檢查。如果條件為 `true`，則執行循環體；如果為 `false`，則終止循環。
- **更新**：在每次執行完循環體後執行，通常用來改變迴圈變量的值。

### 詳細信息
`for` 循環廣泛應用於需要重複執行的場景，特別是數組的遍歷。它的可讀性強於使用 `while` 循環，特別是當迴圈次數已知時。

## 範例
以下是一些 `for` 循環的基本用法範例：

### 範例 1：簡單計數
```java
for (int i = 0; i < 5; i++) {
    System.out.println("計數器: " + i);
}
```
這個範例將輸出編號從 0 到 4 的數字。

### 範例 2：遍歷數組
```java
String[] fruits = {"蘋果", "香蕉", "橘子"};
for (int i = 0; i < fruits.length; i++) {
    System.out.println(fruits[i]);
}
```
這個範例將遍歷 `fruits` 數組，並輸出每一種水果的名稱。

## 解釋
在使用 `for` 循環時，有幾個常見的坑需要注意：
1. **條件錯誤**：如果條件設置錯誤，可能導致無限循環或根本不執行循環。
2. **迴圈變量的更新**：在更新表達式中忘記更新迴圈變量，會導致意外行為。
3. **數組越界**：在遍歷數組時，應確保條件不會超出數組的範圍，否則會拋出 `ArrayIndexOutOfBoundsException`。

## 一句總結
`for` 循環是 Java 中一個強大且靈活的控制結構，適合用於確定次數的重複執行。
