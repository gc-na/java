# الكلمة المحجوزة "default" في جافا: الاستخدامات والخصائص

## ملخص
تشير الكلمة المحجوزة "default" في جافا إلى إمكانية تقديم قيمة افتراضية في واجهات البرمجة، بالإضافة إلى استخدامها في جمل switch لتحديد السلوك الافتراضي عند عدم تطابق أي من الحالات المعطاة.

## الوثائق
### الغرض
تستخدم "default" لتحديد سلوك افتراضي في حال عدم تطابق الشروط المحددة. في سياق واجهات البرمجة، تسمح "default" للمطورين بتوفير تنفيذ افتراضي للطرق دون الحاجة إلى زيادة عدد الفئات المشتقة.

### الاستخدام
- **في واجهات البرمجة**: يمكن استخدام "default" لتعريف طريقة داخل واجهة برمجية بحيث تحتوي على تنفيذ افتراضي.
  
  ```java
  interface MyInterface {
      default void myMethod() {
          System.out.println("هذا هو التنفيذ الافتراضي");
      }
  }
  ```

- **في جمل switch**: تستخدم "default" لتحديد الحالة الافتراضية عندما لا تطابق أي حالة أخرى.

  ```java
  int day = 5;
  switch (day) {
      case 1:
          System.out.println("الإثنين");
          break;
      case 2:
          System.out.println("الثلاثاء");
          break;
      default:
          System.out.println("يوم غير معروف");
  }
  ```

## أمثلة
### مثال 1: استخدام "default" في واجهة برمجية
```java
interface Animal {
    default void sound() {
        System.out.println("صوت حيوان");
    }
}

class Dog implements Animal {
    // يمكن استخدام التنفيذ الافتراضي أو كتابة تنفيذ خاص
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.sound(); // تطبع "صوت حيوان"
    }
}
```

### مثال 2: استخدام "default" في جمل switch
```java
public class DayExample {
    public static void main(String[] args) {
        int day = 3;
        switch (day) {
            case 1:
                System.out.println("الأحد");
                break;
            case 2:
                System.out.println("الإثنين");
                break;
            case 3:
                System.out.println("الثلاثاء");
                break;
            default:
                System.out.println("يوم غير معروف");
        }
    }
}
```

## الشرح
### الأخطاء الشائعة
- **عدم استخدام "break"**: عند عدم استخدام جملة "break" في جمل switch، سيتم تنفيذ جميع التعليمات التالية للحالة المطابقة، مما قد يؤدي إلى سلوك غير متوقع.
  
- **تعارض الأسماء**: عند تعريف طرق في واجهات باستخدام "default"، يجب أن تكون حذرًا من التعارض في الأسماء إذا كانت الفئة المشتقة تقدم تنفيذًا خاصًا.

### ملاحظات إضافية
- يمكن أن تحتوي الواجهات التي تستخدم "default" على طرق متعددة، مما يتيح للمطورين تخصيص سلوك الواجهة حسب الحاجة.
- استخدام "default" في واجهات البرمجة يعزز من قابلية إعادة الاستخدام ويقلل من تكرار الكود.

## ملخص بجملة واحدة
الكلمة المحجوزة "default" في جافا توفر إمكانية تنفيذ افتراضي في واجهات البرمجة وتحدد سلوكًا افتراضيًا في جمل switch.
