# استخدام الكلمة المفتاحية "extends" في لغة جافا: الفهم والتطبيق

## الملخص
تُستخدم الكلمة المفتاحية "extends" في لغة جافا للإشارة إلى مفهوم الوراثة، حيث تتيح لفئة (class) أن ترث خصائص وسلوكيات فئة أخرى، مما يعزز إعادة استخدام الكود ويعزز التنظيم الهيكلي للتطبيقات.

## الوثائق
### الغرض
تُستخدم الكلمة "extends" في تعريف فئة جديدة تستند إلى فئة موجودة، مما يسمح للفئة الجديدة (المشتقة) بالاستفادة من جميع الخصائص والأساليب (methods) التي تمتلكها الفئة الأساسية (الأساسية).

### الاستخدام
لإنشاء فئة جديدة تعتمد على فئة موجودة، يتم استخدام الكلمة "extends" في تعريف الفئة. يمكن أن يكون للفئة الجديدة طرق وخصائص خاصة بها، بالإضافة إلى تلك التي ورثتها من الفئة الأساسية.

### التفاصيل
- **التعريف الأساسي**: 
  ```java
  class ClassA {
      // تعريف الخصائص والطرق
  }

  class ClassB extends ClassA {
      // ClassB ترث ClassA
  }
  ```

- **الوراثة المتعددة**: جافا لا تدعم الوراثة المتعددة (أي، فئة ترث من أكثر من فئة أساسية)، ولكن يمكن استخدام واجهات (interfaces) لتحقيق سلوك مشابه.

## الأمثلة

### مثال 1: استخدام "extends"
```java
class Animal {
    void sound() {
        System.out.println("حيوان يصدر صوت");
    }
}

class Dog extends Animal {
    void sound() {
        System.out.println("الكلب ينبح");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.sound(); // ستظهر "الكلب ينبح"
    }
}
```

### مثال 2: خصائص الوراثة
```java
class Vehicle {
    void start() {
        System.out.println("المركبة بدأت بالتحرك");
    }
}

class Car extends Vehicle {
    void drive() {
        System.out.println("السيارة تسير");
    }
}

public class Main {
    public static void main(String[] args) {
        Car car = new Car();
        car.start(); // ستظهر "المركبة بدأت بالتحرك"
        car.drive(); // ستظهر "السيارة تسير"
    }
}
```

## الشرح
### الأخطاء الشائعة
- **عدم استخدام الكلمة المفتاحية "extends" بشكل صحيح**: يجب أن تكون دائمًا الفئة المشتقة متبوعة بكلمة "extends" ثم الفئة الأساسية. 
- **محاولة استخدام الوراثة المتعددة**: جافا لا تسمح بفئة واحدة أن ترث من أكثر من فئة، لذا يجب استخدام الواجهات لتحقيق هذا السلوك.
- **عدم استدعاء المُنشئ (constructor) للفئة الأساسية**: عند إنشاء فئة جديدة، يجب استدعاء مُنشئ الفئة الأساسية (إذا كان موجودًا) باستخدام `super()`.

## ملخص جملة واحدة
تُستخدم الكلمة "extends" في جافا لتمكين الفئات من وراثة الخصائص والسلوكيات من فئات أخرى، مما يسهل تنظيم الكود وإعادة استخدامه.
