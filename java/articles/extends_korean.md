# Java의 "extends": 상속을 통한 클래스 확장

## 개요
Java에서 "extends" 키워드는 클래스 상속을 구현하는 데 사용됩니다. 이 기능은 기존 클래스의 속성과 메소드를 새로운 클래스에서 재사용할 수 있도록 하여 코드의 재사용성과 가독성을 높입니다.

## 문서화
### 목적
"extends" 키워드는 하나의 클래스가 다른 클래스를 상속할 때 사용됩니다. 상속을 통해 새로운 클래스는 부모 클래스의 모든 공용 및 보호 멤버를 사용할 수 있으며, 이를 통해 객체 지향 프로그래밍의 원칙인 코드 재사용을 극대화할 수 있습니다.

### 사용법
Java에서 클래스를 정의할 때 "extends" 키워드를 사용하여 다른 클래스를 상속받을 수 있습니다. 기본 문법은 다음과 같습니다:

```java
class 자식클래스명 extends 부모클래스명 {
    // 자식 클래스의 추가 속성과 메소드
}
```

이렇게 정의된 자식 클래스는 부모 클래스의 속성과 메소드를 물려받아 사용할 수 있습니다.

### 세부 사항
- Java는 단일 상속만을 지원합니다. 즉, 한 클래스는 오직 하나의 부모 클래스만 가질 수 있습니다.
- 인터페이스를 사용하면 다중 상속을 구현할 수 있습니다.
- 부모 클래스의 생성자는 자식 클래스의 생성자가 호출될 때 자동으로 호출됩니다.

## 예제
다음은 "extends" 키워드를 사용한 간단한 예제입니다:

```java
// 부모 클래스
class 동물 {
    void 소리내기() {
        System.out.println("동물이 소리를 냅니다.");
    }
}

// 자식 클래스
class 개 extends 동물 {
    void 소리내기() {
        System.out.println("멍멍!");
    }
}

public class Main {
    public static void main(String[] args) {
        개 myDog = new 개();
        myDog.소리내기(); // "멍멍!" 출력
    }
}
```

## 설명
- **일반적인 실수**: "extends" 키워드를 사용할 때, 부모 클래스의 생성자를 호출하지 않으면 초기화되지 않은 상태로 자식 클래스가 생성될 수 있습니다.
- **상속의 제한**: Java는 다중 상속을 지원하지 않기 때문에, 한 클래스가 여러 클래스를 상속받으려면 인터페이스를 사용해야 합니다.
- **메소드 오버라이딩**: 자식 클래스에서 부모 클래스의 메소드를 재정의할 수 있으며, 이를 통해 특정 동작을 변경할 수 있습니다.

## 한 줄 요약
Java에서 "extends" 키워드는 클래스 상속을 통해 부모 클래스의 속성과 메소드를 자식 클래스에서 재사용할 수 있게 해줍니다.
