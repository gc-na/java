# Javaにおける「continue」文の使い方と機能

## 概要
Javaにおける「continue」文は、ループ構造内で使用され、次の反復に進むための制御フロー文です。特定の条件が満たされた場合に、現在の反復をスキップしてループの次の反復に移行することができます。

## ドキュメンテーション
### 機能
「continue」文は、forループ、whileループ、do-whileループのいずれかのループ構造内で使用されます。この文を使用することで、条件に基づいて特定の処理をスキップし、ループの次の反復を実行することができます。

### 使用法
以下のように「continue」文を使用します：

```java
continue;
```

「continue」文は、ループの特定の条件が満たされた際に実行されます。通常、if文と組み合わせて使用されます。

### 詳細
- **使用場所**: 「continue」文は、ループ内の任意の位置に配置できますが、通常は条件分岐の内部で使用されます。
- **影響**: 「continue」文が実行されると、ループの現在の反復が中断され、次の反復に移行します。
- **スコープ**: 「continue」文は、内側のループにのみ影響を与えることができます。ネストされたループがある場合、外側のループには影響しません。

## 例
以下は、「continue」文の基本的な使用例です。

### 例1: forループでの使用
```java
public class ContinueExample {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i % 2 == 0) {
                continue; // 偶数の場合、次の反復に進む
            }
            System.out.println(i); // 奇数のみ出力
        }
    }
}
```
このコードは、1から10までの数字の中で奇数のみを出力します。

### 例2: whileループでの使用
```java
public class ContinueWhileExample {
    public static void main(String[] args) {
        int i = 0;
        while (i < 10) {
            i++;
            if (i % 2 == 0) {
                continue; // 偶数の場合、次の反復に進む
            }
            System.out.println(i); // 奇数のみ出力
        }
    }
}
```
このコードも同様に、1から10までの奇数を出力します。

## 説明
- **一般的な落とし穴**: 「continue」文を多用すると、コードの可読性が低下することがあります。特に、ネストされたループ内で使用する場合は注意が必要です。
- **条件に注意**: 「continue」文の条件が誤って設定されていると、意図しない反復がスキップされる可能性があります。
- **ループの終了条件**: ループの終了条件を正しく設定しないと、無限ループに陥る可能性があります。

## 一文要約
Javaの「continue」文は、ループ内で特定の条件を満たす場合に現在の反復をスキップし、次の反復に進むための制御フロー文です。
