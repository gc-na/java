# Java의 while 문: 반복문을 활용하는 방법

## 개요
Java에서 "while" 문은 특정 조건이 참인 동안 반복적으로 코드를 실행하는 제어 구조입니다. 이는 무한 루프와 조건부 반복을 구현할 수 있어 유용합니다.

## 문서화
"while" 문은 조건이 참인 동안 반복적으로 실행되는 코드 블록을 정의합니다. 기본 구문은 다음과 같습니다:

```java
while (조건) {
    // 반복 실행할 코드
}
```

### 목적
"while" 문은 특정 조건에 따라 코드의 실행을 반복할 수 있도록 하여, 반복 작업을 효율적으로 처리할 수 있게 해줍니다.

### 사용법
1. 조건식을 작성합니다. 이 조건식은 boolean 타입이어야 하며, true일 경우 코드 블록이 실행됩니다.
2. 코드 블록 내에서 조건이 변경될 수 있도록 합니다. 그렇지 않으면 무한 루프에 빠질 수 있습니다.

### 세부사항
- "while" 문은 조건이 false가 될 때까지 반복 실행됩니다.
- 조건문이 처음부터 false일 경우, 코드 블록은 한 번도 실행되지 않습니다.
- 제어문을 종료하기 위해 break 문을 사용할 수 있습니다.

## 예제
### 기본 사용 예제
```java
public class WhileExample {
    public static void main(String[] args) {
        int i = 0;
        while (i < 5) {
            System.out.println("i의 값: " + i);
            i++; // i 값을 증가시켜 조건이 false가 되도록 합니다.
        }
    }
}
```
위의 예제는 i가 0에서 4까지의 값을 가지며, 각 값을 출력하게 됩니다.

### 무한 루프 예제
```java
public class InfiniteLoopExample {
    public static void main(String[] args) {
        int i = 0;
        while (true) {
            System.out.println("무한 루프 중: " + i);
            i++;
            if (i >= 5) {
                break; // 조건을 통해 루프를 종료합니다.
            }
        }
    }
}
```
이 예제는 i가 5에 도달할 때까지 무한히 반복됩니다.

## 설명
### 일반적인 오류 및 유의사항
- **무한 루프**: 조건이 항상 참인 경우, 루프는 영원히 실행됩니다. 조건을 적절히 설정해야 합니다.
- **조건의 변경**: 반복문 내부에서 조건을 적절하게 수정하지 않으면 무한 루프에 빠질 수 있습니다.
- **자원 관리**: 반복문 내에서 자원을 할당한 경우, 적절히 해제하지 않으면 메모리 누수가 발생할 수 있습니다.

## 한 줄 요약
Java의 "while" 문은 주어진 조건이 참인 동안 반복적으로 코드 블록을 실행하는 제어 구조입니다.
